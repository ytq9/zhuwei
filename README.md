# 烛帷

朋友围坐，你开口，骰子落地。帷幕后，烛火未灭。

烛帷是一款 **D&D 第 5 版** 多人网页跑团：2–5 名玩家，**AI 当 KP**。角色固定 3 级开团，规则按 5e 记账（生命、环位、引导神力、战争祭司、短休/长休），叙事、裁决、对抗由 KP 当场写，不剧透、不为了主线改骰。

当前模组：《**黑橡居酒屋的第三份遗嘱**》——剑湾小镇暮烛镇的社交与调查短团，约 3–5 小时，可续长线。

仓库：[github.com/ytq9/zhuwei](https://github.com/ytq9/zhuwei)

## 能做什么

### 开房与入座

- 登录后进酒馆。房主开一桌，生成房间码；朋友用房间码加入（最多 5 人）。
- 大厅里各自建卡，锁卡后房主开团。
- 局内可以离开；房主可以请离（点一次确认）。被请离的人人物卡还在，用同一房间码可以再坐回来。
- 房主也可以把房主交给桌上另一人。

### 建卡

完整 5e 3 级卡：种族、职业、子职、点买、背景、技能、法术、装备。锁卡后才能入戏。人物栏会标出所在地点；分头时还能看到自己相对别人差了几拍。

### AI KP

- 玩家打字或按住说话（语音转写，确认后再进桌）。KP 用完整、清楚的现代中文旁白，一次主要写一个人。
- 关键处会要你掷骰；环位、引导神力、战争祭司等 **先点再用，掷出才扣**。
- 失败会留下还能看见的线索和下一步，不会把秘密从旁白里漏出来。
- 线索钉上线索板；日志里留下这一拍发生了什么。
- 不同地点可以同时有 KP 在写，这边开口不必等另一边写完。

### 分头与时间拍

桌上是 **同一条时间线**。谁做事谁记拍。两边最多相差 **3 拍**：领先的一边会被拦住，等落后的一边补上，或写「我在这里等」。汇合时把两边的钟对齐，不会出现一边忙了一夜、另一边只问了一句却同时回到大厅。

短休大约 6 拍，长休大约 18 拍。全员同意才结算；只有提出休息的那一边真正休息，另一边可以继续活动，活动够拍之后时间对齐、休息结束。

### 组队

人物栏可以邀请同场景的人组队。组队后去留、移动当作一个整体。

- 每队有一名队长，默认是发起邀请的人。队长可以把队长交给队员。
- 队员要说话或行动，先进队内缓冲，全队看得见；队长批准后才进桌，KP 把它当成 **这个队员独自开口**，不代表整队。
- 队长本拍内没批准，缓冲自动消失。
- 邀请约一分钟无人应答会取消；邀请人也可以自己取消。随时可以离队。
- 有人离开当前场景时，对话里会有一行小字：谁去了哪里。

### 战斗

进入战斗后桌上出现战斗条：先攻、当前回合、生命。可以说话（例如「我跟上」），KP 写完再一起裁。被发现的同伴会拉进同一场战斗。不在这个地点的人看不到这场打。

### 语音

按住说话 → 转成文字 → 你确认后再发送。KP 旁白可以用语音读出来。

## 模组：《黑橡居酒屋的第三份遗嘱》

暮烛镇。老板赫斯·黑橡死在酒窖门口，嘴里塞着一片黑橡叶。三份遗嘱，三个说法：女儿莉安、书记官瓦罗、「远房表弟」奈斯。酒窖的门是新钉上的。门缝里有人在哼摇篮曲。

三章结构：守灵夜 → 酒窖与神龛 → 余波。社交、搜查、一场可以谈下来的对峙。线索会断，人会死。唱出那首歌、无证据当街动手、把酒窖交给不该拿的人，都会把镇子推向更糟的结局。

## 本地运行

需要 **Node.js 20+**。

```bash
git clone https://github.com/ytq9/zhuwei.git
cd zhuwei
npm install
npm run dev
```

开发服务默认 `http://localhost:8080`。登录后进酒馆，开一桌或输入房间码。

没有配置数据库时，用内嵌 PGLite（Postgres 的 WASM），预览即可跑。配置了 `DATABASE_URL` 则走 Neon / 普通 Postgres。

生产构建：

```bash
npm run build
npm run preview
```

其它命令：

| 命令 | 作用 |
| --- | --- |
| `npm run typecheck` | TypeScript 检查 |
| `npm test` | 脚本与鉴权单测 |
| `npm run lint` | ESLint |
| `npm run db:migrate` | 跑 migrations |

### 环境变量

| 变量 | 用途 |
| --- | --- |
| `XAI_API_KEY` | KP 与语音（xAI） |
| `DATABASE_URL` | 生产 Postgres；不设则用 PGLite |
| `VITE_AUTH_ENABLED` | 是否开登录。生产配了数据库时应为开启 |

不要把 `.env` 提交进仓库。

## 技术栈

- **TanStack Start / Router / Query** + Vite + React 19
- **Better Auth**（登录）；预览里用开发用户，生产走真实会话
- **PGLite** 本地 / **Neon（pg）** 生产
- AI KP：结构化 JSON（旁白、检定、花费、地点、战斗补丁），再由引擎结算 5e 资源

## 目录

```
src/
  components/     酒馆桌面、建卡、登录、战斗条
  routes/         首页、酒馆、房间 /table/$code、登录注册
  lib/dnd/        种族职业、点买、库存、掷骰加成、短休长休
  lib/kp/         KP 引擎、提示词、时间拍、组队、地点、战斗
  lib/module/     模组（黑橡居酒屋）
  lib/table/      房间、发送、结算、请离
  lib/voice/      语音进出
migrations/       用户与桌面状态
scripts/          迁移、预览烟测、构建辅助
```

核心约定：

- **一拍**：桌上的一个时间单位。做事记拍；分头最多差 3 拍。
- **库存先于旁白**：法术位、引导神力等以引擎扣减为准，模型不能口胡回满。
- **地点可见**：只看见自己所在场景的对话与战斗；自己说的话自己始终看得见。
