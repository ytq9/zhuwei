# ADR 0127：分段剧情摘要只作为本人记忆的检索提示

- 状态：已接受
- 日期：2026-10-06
- 依据：用户要求继续完成 handoff 的剧情摘要；[ADR 0111](0111-a-layered-knowledge-directory.md) 已记录“分层目录与模型分段摘要都做”的选择。[SPEC 0016 §4.3/§4.5](../specs/0016-coarse-forms-frozen-adjudication-context-and-typed-claims.md) 与 [SPEC 0001 §9](../specs/0001-llm-kp-responsibility-contract.md) 决定知识与引用边界。
- 取代范围：补齐 ADR 0111 的后半部分，沿 [ADR 0115](0115-long-play-context-stays-bounded.md) 的现有目录与原文回读，不改变已裁定条款。

## 决定与原因

长期段从该角色完整知识集合按场景、虚构天和取得顺序切出，而不使用本轮因相关度而变化的目录余项作为身份。最近六轮保留原文，每段最多 32 条、12,000 字；不足整段的当天尾部继续等待。每条来源绑定原 KnowledgeRecord 与实际正文的精确 hash。世界事实指针只解析本人持有的固定版本，不把私有创作材料或其他角色知识送进摘要请求。

模型只写一段最多 240 字的检索摘要，输出请求上限 1,000 token；不递归概括已有摘要。每组最多显示两段、每角色最多八段，均标为不可引用的目录提示。裁决仍需按原 handle 读取原文，既有 40 条与正文预算不变；若提示挤占必要正文就不加入提示。

摘要使用既有 `context` 调用账本、原行动预算和请求调用 scope；成功行动的必要旁白发布后，每个请求最多处理一段。因回答或掷骰完成的行动回到同一源行动的冻结目录。摘要失败不改变已成功行动，不开后台常驻调用。该可选调用会延长当次请求的响应等待；真实质量和费用仍须另有预算才能测量。

完成、未知、未发送状态沿原账本恢复，未知不重采样；只有明确未发送才可续发。来源、更正分支或持有者不匹配时不采用旧结果。调用、宿主、段来源与请求中的持有者／正文必须互相绑定，不能把另一人的结果接到当前目录。

复用现有 DO 宿主上下文表，扩展其 `CHECK` 并保存旧行；不新增 D1 表。完整归档保留精确调用与宿主，恢复时检查唯一归属；原世界事件和原始知识不被摘要改写。

## 验收接缝

`knowledge-summary.test.mjs` 覆盖分段、本人正文、不可引用、失效和本地 SQLite 迁移；`knowledge-summary.room.test.ts` 覆盖真正行动完成后的摘要调用、预算耗尽和完整归档恢复。实际命令与结果只记本轮回执。
