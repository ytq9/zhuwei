# ADR 0116：死亡豁免按看得见的样子叙述

- 状态：已接受
- 日期：2026-10-05
- 依据：round175 的 `combat-strike-down` 里，奈斯倒地后在自己的回合做了一次死亡豁免，旁白写成"死亡豁免已累计成功一次、失败零次"。写手拿到的材料就是这句计数（`目标进行了死亡豁免，目前累计成功 N 次、失败 M 次`）。用户裁定："死亡豁免旁白要改"。
- 当前规则：[SPEC 0012 §12.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)
- 取代范围：死亡豁免 Claim 带累计次数的写法（实现选择，此前没有 ADR 记录）。

## 决定

死亡豁免的 Claim 只写看得见的状态：
- 普通一次："目标仍昏迷不醒。"
- 三次成功："目标的伤势稳定了下来，仍然昏迷。"
- 天然 20："目标醒了过来。"
- 三次失败："目标没能撑过去。"，死亡另由 `CreatureDied` 讲。

累计次数和天然骰面不进 Claim，也就不进旁白材料。

## 影响

- 骰子记录里的死亡豁免条目（`dice-results.ts`）仍显示累计次数；那是掷骰记录，不是旁白，本次不改。
- 本次没有真实调用验证。
