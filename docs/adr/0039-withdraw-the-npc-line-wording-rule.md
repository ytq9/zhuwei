# ADR 0039：撤回 NPC 台词的句式要求

- 状态：已接受
- 日期：2026-09-23
- 依据：用户于 2026-09-23 看过 round106 的结果后说明：“我们不要求句式怎样，只需要让 NPC 知道当时发生的事情，他知道些什么，他是什么样的人，然后根据这些来回复。”
- 当前规则：[SPEC 0009 §6 叙述协议](../specs/0009-failure-pacing-conclusion-and-interaction.md)
- 取代范围：取代 [ADR 0037](0037-branch-bound-outcomes-and-quoted-npc-lines.md) 决定第 2 条“NPC 台词以直接引语呈现”。决定第 1 条（检定分支不越过自己的摘要）不受影响。

## 决定

1. SPEC 0009 §6 删除直接引语一段。叙述协议不规定 NPC 台词用直接引语还是转述。
2. 两份旁白提示都删去这条要求：现役的 `narration-text.ts`（`plainText-v1`），以及旧式的 `narration-vnext.ts`。旧式提示原有的“不要把台词或内部字段逐字拼起来”也不恢复，只保留“不要把内部字段逐字拼起来”，因为前半句同样是在规定句式。`chinese-expression.ts` 的“用通顺的直接引语转述”改为“用通顺的话转述”。
3. 为这条要求加的两个测试和 SPEC 0009 的两条门一起删除。

## 后果

- NPC 回复靠什么，回到用户说的三件事：当时发生的事、NPC 知道什么、NPC 是什么样的人。前两份材料之外的“当时发生的事”，目前的 NPC 决策上下文里没有，另行处理。
- 以上提示都还没有部署，所以不涉及在途工作。
