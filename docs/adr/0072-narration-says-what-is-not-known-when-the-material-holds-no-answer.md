# ADR 0072：材料里没有答案时，旁白说不知道

- 状态：已接受
- 日期：2026-09-29
- 依据：用户看过 round150 发布的正文后指出，不知道的就应该说不知道。
- 当前规则：[SPEC 0016 §8.3](../specs/0016-part-c-compound-actions-and-claims.md)。
- 取代范围：无。补足 §8.3 “不新增冻结材料之外的事实”在被问到未知内容时的做法。

## 原因

9DCMQN 的玩家问“什么纸”。冻结材料里有两条相关记录：开场时瓦罗把一份盖印的文件按在账台上；奈斯说过“这卷纸”“这份遗嘱”。没有任何记录说明奈斯那卷纸是什么、在谁手里，也没有记录说明它和瓦罗的文件是同一份。

旁白把两条记录合成了一个答案。[round150](../agent/receipts/vnext-round150-validation.md) 里三次审核改掉了动作主体和被改动的条件，合并本身保留到了发布正文。规格原先只写了不能新增事实，没有写被问到没有记录的事时该怎么答；生成和审核的提示里也没有。

## 决定

当前行动问到的事在冻结材料里没有答案时，旁白如实说明角色目前不知道，只讲材料里有的部分。材料没有写明是同一个的人或物，不说成同一个。

这条规则写进生成和审核共用的事实边界，两边按同一标准执行。旁白策略升为 `zhuwei.text-narration/v6`。

## 影响

- 生成和审核提示各多 63 字。
- 玩家会更常看到“你还不知道”这样的回答。这是角色知识的真实状态，不是故障。
- 这条规则不补材料。NPC 提到一件东西而世界里没有它的记录，仍然是提案阶段留下的缺口。
