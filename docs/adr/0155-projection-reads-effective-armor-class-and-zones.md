# ADR 0155：投影读取法术修正后的 AC，并画出持续区域

- 状态：已接受
- 日期：2026-10-11
- 依据：用户同意修改投影源文件，让法术效果在页面上可见（见 ADR 0151、0154 的影响一节）。
- 当前规则：条款不变。[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（投影与机械读取同一有效值来源）、[SPEC 0014 §§6、9.3](../specs/0014-observer-tactical-map-and-environment.md)（战术投影列出已知的持续区域）。
- 取代范围：无。

## 原因

- 投影自己又算了一遍 AC（`projectedArmorClass`），只认护盾术；角色栏显示的是装备算出的 AC。法师护甲、信仰护盾生效后，页面上的 AC 与攻击检定所对的 AC 不同，正是 SPEC 0012 §10.1 禁止的两份来源。
- 战术投影的 `knownZones` 恒为空，地图画不出云雾术和沉默术的区域。

## 决定

1. **AC。** 投影的有效 AC 改读 `effect-modifiers` 的 `effectiveArmorClass`，与攻击检定同一函数。`combatControls.vitals` 增加 `armorClass`，角色栏优先显示它，没有时退回装备算出的值。
2. **区域。** `knownZones` 从区域效果生成：每个区域一项，地面上画成以球心为中心、半径为法术半径的十六边形，高度从球心下方一个半径到上方一个半径，标签为“浓雾（重度遮蔽）”或“沉默区域”，带开始时刻和（限时的）到期时刻。场景里看得见的人都能看到。

## 影响

- 法师护甲、信仰护盾、护盾术生效时，角色栏的 AC 与命中判定一致；地图画出云雾和沉默区域。
- 角色栏的速度仍取装备与种族的值；地图的移动预算已经读条件和速度修正（冷冻射线）。
- 读模型的 `vitals` 多一个可选字段；战术投影的 `knownZones` 从空变为实际区域，空间修订号随之变化。
