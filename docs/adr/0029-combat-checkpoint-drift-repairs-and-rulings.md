# ADR 0029：`72201ea` 检查点后战斗门的修复与裁定

- 状态：已接受
- 日期：2026-09-18
- 依据：用户于 2026-09-18 要求逐类修复棘轮里的红测，需要裁定的点单独问；下列四项裁定均取所提的推荐项。
- 当前规则：[SPEC 0012 §4.2 区域目标](../specs/0012-authoritative-combat-mechanics.md)、[SPEC 0012 §10.2 专注](../specs/0012-part-b-abilities-damage-and-conclusion.md)
- 取代范围：不取代既有条款；§4.2 与 §10.2 各补一句先前未明示的实现选择。

## 背景

2026-09-07 的检查点提交 `72201ea`（507 个文件）改变了战斗机械的多处行为，当时没有 CI，SPEC 0012/0013 声明的门两天后才被发现红了 32 个用例（二分记录见 [2026-09 日志](../refactor-log/2026-09.md) 的 2026-09-11 条目）。逐个定位后分成三种情况：产品缺陷、夹具落后于已裁定的不变量、规格未明示的实现选择。

## 产品缺陷（修复，不涉及裁定）

1. 环境特技、环境能力及其 fold 对 `combatRuntime.definitions` 里读出的能力再次调用编译器。武器能力在那里是注册记录，编译器拒绝调用方自带的图，于是所有用真实武器发起的环境特技都被判"能力不可用"。`frozenAbilityHashes` 对注册记录沿用冻结哈希，只对原始定义编译一次（SPEC 0013 §3.3：注册后不重编译）。
2. 危险结算世界 NPC 时用 `environment.ts` 自己的基线视图，而 `DamagePacketResolved` 的 fold 用 `damage.ts` 的 `worldDamageTarget` 重建；两者字段不同，step 提交的事件被自己的 fold 拒绝。现在只有一个构造器。
3. 危险的伤害包 `targetPatch` 混入了倒地后果；fold 只按伤害流水线重建伤害包（SPEC 0012 §11）。倒地留在 `EnvironmentAreaTargetResolved` 与 `ConditionChanged`。

## 夹具落后于已裁定不变量（改夹具）

- 反应法术资格只认注册时冻结的图（SPEC 0013 §4.4）；夹具手写的 Shield/Counterspell 改为经生产编译器注册。`mechanicalKey` 在这两类定义上已无作用，从夹具删除。
- 玩家战斗资源池须由角色档案同名键背书（SPEC 0012 §3.2）；长施法与触发排序夹具补齐档案。
- 技能熟练来自角色卡，"特殊近战攻击一律熟练"已退役；爱丽丝在推撞对抗中登记运动熟练。
- 区域按几何包含施法者与盟友；2014 远程攻击对 5 尺内倒地目标有优势、5 尺内有敌对生物有劣势，两者相抵。测试期望按规则更正。
- 攻击的伤害批次为每个分量预留重击骰，骰带按分量成对给出。

## 裁定

1. **区域候选只包括具有规范位置与占位的实体。** `environment` 类实体是危险的控制者、不占据空间，不进候选；可破坏场景要素仍按 SPEC 0014 的要素路径受区域影响。未选的方案是给环境实体位置与占位，若需要另行立项。
2. **专注豁免骰可与触发它的伤害骰同批请求。** DC 在伤害结算后按 §10.2 公式确定；伤害完全归零时预取的骰面不被消耗、不产生豁免。
3. **接受三项附加的公开输出。** 待选目标带 `maximumTargetCount`，检定请求的冻结参数带 `mode`，攻击劣势原因把中毒细分为 `poisoned2014`。
4. **step 边界只把有意的校验失败转成通用拒绝。** 规则模块里 651 处有意的 `throw` 改为 `RulesValidationError`，step 的兜底 catch 与区域几何的 catch 只把它转成拒绝；step 与 fold 之间、权威状态内部的一致性检查改为 `RulesInvariantError`，连同引擎错误等一切不是有意抛出的异常原样传播。fold 内的校验仍可以拒绝伪造输入，因为它抛的是校验错误。玩家看到的文案不变（SPEC 0014 §6 防泄露）。

## 后果

- SPEC 0012 声明的四个门与 SPEC 0013 的触发排序门全部转绿，单测基线随之收紧。
- `docs/agent/task-combat-mechanics-failures.md` 任务书完成并删除。
- `step` 抛出的异常由房间层按现有请求边界处理为失败并带堆栈记录；本决定不新增遥测事件。
