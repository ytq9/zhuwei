# ADR 0158：命令术由 Rules 替目标执行

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150），并对“到了目标的回合，命令怎么执行”选择了“Rules 自动执行”：施法者从 SRD 写明的五个命令里选一个，玩家与 NPC 一样处理。这是最后一批：命令术。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（命令术）。
- 取代范围：无。

## 原因

- 命令术的效果在目录里只是描述（“下回合执行一个不直接有害的单词命令”），施放时整体被拒。
- 施放时没有地方说出命令词；行动列表只会发出目标。到了目标的回合，也没有由 Rules 替生物行动的机制。

## 决定

1. **命令词。** 命令词是施放参数 `command`，取值限于靠近、放下、逃跑、趴下、停止。没有给出时，Rules 像选目标一样先打开一个待决选择（`commandWord`），给施法者五个选项；回答后接着施放，选择之前不扣法术位、不掷骰。读模型和页面按选项按钮呈现它。
2. **效果。** 目标豁免失败时得到修正效果 `commanded`，记录施放时选定的命令词，持续到目标下一个回合结束。
3. **执行。** 被命令者回合开始的流程走完后（回合开始伤害、躲藏察觉、预备动作），Rules 记一条内置动作 `action:obey-command`：用掉动作和附赠动作；趴下则倒地；放下则逐件把主手、副手的物品放在脚下；停止、放下、趴下都用尽本回合的移动；靠近沿直线走向施法者，进入其 5 尺内即停；逃跑先疾走，再沿直线远离。直线走位在场景边界内、按 5 尺一步从最远的候选位置往回试，取移动步骤接受的第一个；不引入 NPC 走位规划，避免模块之间的循环依赖。随后命令效果结束，Rules 替它结束回合（回合结束的重复豁免照常结算）。
4. **例外。** 无法行动的目标不能服从，效果结束，它的回合照常。命令引发的移动若打开反应窗口，回合留给控制者结束；动作和附赠动作已经用掉。

## 影响

- 命令术可以施放并生效；至此法术目录里所有曾经施放必被拒的法术都能执行。
- 尚未实现：对不死生物无效、目标听不懂施法者的语言时无效（缺少生物类型与语言数据）、命令“直接有害”时无效。
- 现有的移动步骤不检查场景边界，NPC 走位规划另行检查；命令术的走位与后者一致，玩家自己的移动是否检查边界本次不变。
- 不改持久化结构的外层；修正记录多一个可选字段，新增一种待决选择。
