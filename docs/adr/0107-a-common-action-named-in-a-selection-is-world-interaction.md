# ADR 0107：选择里的常用动作名读作世界互动

- 状态：已接受
- 日期：2026-10-05
- 依据：第 169 批真实验证的爬沟用例（169-1）。在"去别处只能写 goTo"这句指引下，KP 在填写阶段调用补选工具，要加一个叫 `goTo` 的类型。按原条款，这是未知标识，补选读不成，整个行动以"格式检查未通过"失败，KP 没有修订的机会。用户确认修改 SPEC 0016 §7.2（"按此改"）。
- 当前规则：[SPEC 0016 §7.2](../specs/0016-part-c-compound-actions-and-claims.md)
- 取代范围：无。扩展 [ADR 0064](0064-ruling-kinds-are-decision-values-and-a-selection-naming-one-is-read-without-it.md) 对裁决名的处理。

## 决定

1. **处理方式。** 选择或补选里出现 `VNEXT_COMMON_ACTION_KINDS` 中的名字（walkTo、goTo、climb 等）时，按选了 `worldInteraction` 读取，重复的只算一次。
   - 首轮选择因此加载世界互动表单。
   - 世界互动已加载时，补选没有新增，按已有规则重新填写一次，不再提供选择工具。
2. **范围。** 其余未知标识仍然拒绝。
3. **不加提示词。** 指引里的措辞改为"只能写 commonAction goTo"（`21423232`），另作处理。

## 影响

- 解析选择的规则改了。Room 用同一函数读取存下的补选，所以重放的结论与当时一致。
- 本次之前存下的补选里没有常用动作名，原来就会失败，不受影响。
