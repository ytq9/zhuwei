# ADR 0053：感知事实跟着观察者的记忆冻结

- 状态：已接受
- 日期：2026-09-25
- 依据：每次交互都会为在场的观察者各写一条感知事实（`worldInteractionSensoryEvidence`，例如“莉安看见外乡人报出姓名”），观察者同时得到一条内容相同的记忆。凡是涉及场景和场景里的人的事实，冻结时一律纳入，所以感知事实随房间一起增长：[ADR 0051](0051-unread-memories-are-read-when-named.md) 之后，16 轮测试里它们每轮约 750 字节，模组事实清单每轮约 570 字节。观察者那条记忆没被读取时，模型视图本来就把这条事实一起隐藏（[ADR 0048](0048-each-character-carries-its-latest-six-rounds.md) 第 5 条），冻结它没有读者。用户同意让冻结内容不再随房间增长（“可以”）。
- 当前规则：[SPEC 0016 §4.3](../specs/0016-coarse-forms-frozen-adjudication-context-and-typed-claims.md)（条款不变）
- 取代范围：感知事实不论观察者的记忆是否被读取都冻结的做法。

## 决定

1. 观察者是行动者或 NPC、并且持有这条感知的记忆时，只有这条记忆被读取，感知事实才冻结，并列进模组事实清单。其他事实照旧纳入。
2. 规则侧绑定的仍是完整事实框架的 hash，冻结的清单只是读到的那部分，这与以前一样。
3. 按编号调回一条旧的感知记忆时，模型看到的是记忆本身的内容；那条感知事实不在冻结上下文里，不能单独引用。

## 后果

- 16 轮测试：第 8 轮到第 16 轮，冻结上下文每轮多约 4,300 字节，[ADR 0051](0051-unread-memories-are-read-when-named.md) 之后是 5,700；感知事实和模组事实清单不再增长。
- 还在增长的：NPC 视图里的完整记忆目录、知识目录和未读清单（每轮约 2,000 字节），调取编号（约 1,100 字节），知识目录条目（约 600 字节），摘要目录（约 500 字节）。
