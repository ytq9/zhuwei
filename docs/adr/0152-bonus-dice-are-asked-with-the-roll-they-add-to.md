# ADR 0152：祝福术与神导术的加值骰随所加的掷骰一起请求

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150）；对神导术“由目标决定用在哪次检定”选择了“自动用在下一次检定”。这是第二批的第二步之一：祝福术、神导术。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（加值骰）。
- 取代范围：无。

## 原因

- 祝福术与神导术的效果在目录里只是描述（“攻击与豁免 +1d4”“一次属性检定 +1d4”），施放时整体被拒。
- Rules 的每次 d20 掷骰都是“选中的面加固定调整值”，没有在 d20 上再加骰子的先例。各处掷骰的用途键和冻结参数各不相同，总值也在各自的结算函数里计算。
- 骰面按用途键整组交回，同一个用途键下多加一个骰项会混进 d20 的面里，影响优势和劣势的取面。

## 决定

1. **目录。** 祝福术的修正是 `d20BonusDie`（d4，攻击与豁免），神导术是 `d20BonusDie`（d4，属性检定）并写明“加值骰用过即结束”。
2. **派生。** `effect-modifiers` 的 `d20BonusDie` 给出某生物某类掷骰该加的骰子：取最大的一枚；同样大时先用持续的，不先用一次性的。
3. **请求。** 每处建 d20 请求时，按掷骰者身上的效果追加一项 `<用途键>:bonus`，与那次 d20 同批请求。一次性的骰子在请求提交时随 `EffectEnded`（`bonusDieUsed`）结束；同一批里它只随第一次掷骰。神导术靠专注维持，它结束后专注随之结束（ADR 0150）。
4. **总值。** 各处结算把这项的骰面加进总值；自然 1 和 20 仍只看 d20。攻击结果、豁免结果、重复豁免事件在有加值骰时记录 `bonusDie`；死亡豁免的 `roll` 是 d20 加加值骰，`natural` 仍是 d20。
5. **接入的掷骰。** 能力攻击（含瞄准某点）、借机攻击、能力与法术豁免、专注豁免（预留与补掷）、环境扰动的专注豁免、死亡豁免、回合结束的重复豁免、先攻（单个生物的先攻条目）、跳跃、躲藏与搜索、医疗稳定、擒抱与推撞对抗的双方、反制法术检定。
6. **不接入的。** Rules 在回合开始或移动后自动替生物掷的躲藏察觉不使用、也不消耗神导术：那不是生物自己选择做的检定，一次性的骰子不该被它用掉。

## 影响

- 祝福术、神导术可以施放，并在上面这些战斗内的掷骰中生效。
- 尚未接入的：KP 裁定的检定（世界交互与自由行动的 `FrozenCheck`）、地图要素的环境危险豁免、对地图要素的攻击与环境特技。前两类在回放时按事件里的骰面重算结果，需要扩展事件结构，留到后续提交；在那之前，战斗外施放的神导术要到下一次战斗内的检定才会用上。
- 猎人印记（伤害骰与转移印记）在第二批的另一份提交里。
- 不改持久化结构的外层；结果记录多一个可选字段。
