# ADR 0159：猎人印记可以转到新的目标身上

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150）。ADR 0153 让猎人印记生效时留下了一项：被标记的生物降到 0 生命值后，SRD 允许施法者在之后的回合用附赠动作把印记转到新的生物身上。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（猎人印记）。
- 取代范围：无。

## 原因

- 印记的目标降到 0 生命值后，专注还在、法术位已经花掉，但印记再也用不上；施法者只能结束专注、重新施放。
- 灵体武器已经有“效果持续期间授予的动作”（ADR 0156）；转移印记是同一类东西，只是授予的条件不同。

## 决定

1. **授予条件。** 修正效果可以写明 `grantsWhenTargetDown`：它的目标不在、已死或生命值为 0 时，效果授予施法者这些动作。法术目录用 `movesWhenTargetDown` 标出可转移的修正；编译法术时同时编译一个只能被授予的附赠动作 `<法术定义>:move`，射程与视线要求取自法术本身，不列入施法者自己的能力。
2. **执行。** 动作的效果 `moveModifier` 找到施法者这道法术现有的修正记录，记一条新事件 `EffectRetargeted`，把记录的目标换成所选生物。记录的编号、剩余时间、专注关系都不变；按虚构时间计的到期点改读新目标的时间线，到期时刻不变。不消耗法术位。
3. **之后。** 新目标站着时，动作不再列出、也不能使用。转移这一步的叙述材料写“印记转到了这个目标身上”。

## 影响

- 猎人印记的目标倒下后，施法者可以在后面的回合把它转走，继续享受武器命中的 1d6。
- 新增一种事件；修正记录多一个可选字段。不改持久化结构的外层。
