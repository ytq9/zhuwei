# 一次窄修订可以补齐字段或重判未生效裁决

- 状态：已接受（用户于 2026-09-09 明确决定）
- 日期：2026-09-09
- 关联规格：SPEC 0016
- 取代范围：取代"首份草稿即冻结"以及"修订只能修格式"两项限制
- 规则所在：[SPEC 0016 §7.2](../specs/0016-coarse-forms-frozen-adjudication-context-and-typed-claims.md)

## 背景

原先的窄修订只允许修复格式错误。但 Rules 的精确诊断经常指出的是语义问题——少一个字段、或者一个尚未生效的裁决判错了。只能改格式意味着这类诊断无法被利用，只能整份拒绝重来，白费一次完整调用。

## 决策

在确认、随机或执行之前，KP 可以依据精确诊断补齐字段或重新判断尚未生效的裁决。修订使用同一冻结上下文、唯一填写草稿及已加载表单，支持绑定源版本的差量补丁或完整替换；补丁不限于最初报错的字段。合成之后整份重新走完整本地与 Rules 校验——合成成功不等于行动合法。

## 影响

仍然只有一次；三轮以及新的费用/等待预算未启用。调用预算与恢复合同统一服从 SPEC 0016 §7.2。任一操作不能应用则整份拒绝，不保留已应用前缀，不产生游戏效果。
