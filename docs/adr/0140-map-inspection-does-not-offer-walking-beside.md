# ADR 0140：地图查看人物或物件时不再提供走近按钮

- 状态：已接受
- 日期：2026-10-11
- 依据：用户测试战术地图时指出“走到什么身边的功能也不需要”，随后明确确认删除地图里的走近操作，保留点空地移动及文字行动中的走近。
- 当前规则：[SPEC 0014 §4](../specs/0014-observer-tactical-map-and-environment.md)
- 取代范围：此前地图探索面板的选人／物后“走到旁边”操作；不取代自然语言裁决、空间找路和战斗移动。

## 原因与实现边界

地图已经能够点选人物或物件查看详情，再在同一面板放一个走近选择器，增加了操作和阅读负担。保留空地选点即可表达场内移动，带有交谈、观察或接触目的的走近由自然语言行动表达。

删除展示组件中的选择器、按钮及其选中状态派生，同步交互测试。保留实际空间事务和找路实现，不改已保存的位置、事件或地图结构，不需要房间迁移。
