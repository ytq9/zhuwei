# ADR 0112：工具、武器与护甲熟练

- 状态：已接受
- 日期：2026-10-05
- 依据：
  - 修上锁的门时发现，检定没有工具熟练：游荡者撬锁只按敏捷算。
  - 用户问"工具熟练是 dnd 规则中要的吗，有的话就加上，哪种属性检定让 kp 自己组合"，随后要求把未覆盖的都补上，并问"还有其他的道具吗？护甲和武器熟练呢？属性由 KP 按做法定"。
  - SPEC 0004 §4 原有"技能/工具熟练只在适用时加入"，但只有技能进了 Rules。武器攻击一律加熟练加值，护甲没有任何熟练限制。
  - 职业、种族、子职给的熟练只写在说明文字里，赌具、乐器、矮人工匠工具、战斗大师工匠工具、知识领域技能和游荡者专精都没有让玩家选。
- 当前规则：[SPEC 0004 §4](../specs/0004-kp-and-noncombat-mechanics.md)
- 取代范围：无。

## 决定

1. **熟练是数据。** 角色目录写明每个职业、种族、子职与背景给的工具、武器与护甲熟练，以及让玩家自选的那几项。建卡向导和开房时的人物种子用同一组函数推出熟练，旧人物卡也按职业、种族、子职与背景推出；只有自选的那几项要人物卡记着。
2. **工具和技能放在一起。** 工具熟练并入 Rules 角色记录的 `proficientSkills`。检定的 skill 栏写工具 id（如 `thieves-tools`），Rules 与 KP 两边原有的加值计算照旧，专精也能落在盗贼工具上。用哪种属性由 KP 按做法定，服务器不限制。
3. **武器按类别与种类。** 每把武器有类别（简易、军用）和种类：目录里的武器以自身 id 为种类，自建物品可以写明它是哪种标准武器。角色记录的 `proficientWeapons` 列出类别和单件武器，攻击只在列出时加熟练加值。没有这一栏的生物（NPC 的属性块）视为熟练。
4. **护甲按种类。** `proficientArmor` 列出轻甲、中甲、重甲、盾牌。穿戴未列出的护甲或盾牌时：
   - 涉及力量或敏捷的检定、豁免与攻击检定加一个劣势来源；
   - 施法、准备法术和反应法术都被拒绝。
5. **新版本。** 装备目录、人物熟练和 NPC 机械三份规则文档升到 v2，vNext 运行清单随之换新（见 [ADR 0113](0113-a-new-runtime-version-retires-open-rooms.md)）。

## 影响

- 建卡向导在已有步骤里增加选择；开局装备里不熟练的护甲或武器不能选（2014 原文为"若熟练"）。
- 检定 skill 栏的说明提到工具 id，每次提案请求多约 19 token。
- 徒手攻击仍按熟练算（2014 中人人对徒手打击熟练），伤害仍是 1d4＋力量，与 SRD 的 1＋力量不同，本次没有改。
