# ADR 0104：战斗地图上的动作先算数，旁白事后写

- 状态：已接受
- 日期：2026-10-05
- 依据：第 166 批真实验证中，玩家在战斗地图上的移动、躲藏和结束回合仍走旧版旁白：它的规则检查常拒掉模型写的距离和氛围，能通过的稿子里又有编出来的先手顺序、距离和 NPC 动作。改走新版说明旁白时，用户选择"动作照算，旁白可重试"。
- 当前规则：[SPEC 0014 §4](../specs/0014-observer-tactical-map-and-environment.md)
- 取代范围：[ADR 0091](0091-map-moves-and-structured-combat-actions-go-straight-to-rules.md) 中"提交后的结果与其他行动一样叙述"所隐含的旧版旁白路径。

## 决定

1. 战斗中的结构化动作（移动、攻击、基础动作、结束回合）先由 Rules 提交。
2. 提交后，按 Rules 为观察者生成的说明写旁白并经审核，与 NPC 回合（ADR 0101）相同。
3. 旁白写不成时，动作已经生效，玩家可以重试旁白，战斗节奏不被模型卡住。
4. 这与世界中的行动不同：那里的旁白在提交前写好，写不成则行动不生效（ADR 0026）。

## 影响

- 战斗动作涉及的每种事件都要有说明，或明确列为不出说明的记录；缺一种会让说明生成失败。
- 遭遇之外的地图移动仍不写旁白（ADR 0091）。
