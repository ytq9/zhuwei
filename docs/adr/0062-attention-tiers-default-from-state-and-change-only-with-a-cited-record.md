# ADR 0062：注意档位由 Rules 按权威状态给默认，KP 只改有记录依据的例外

- 状态：已接受
- 日期：2026-09-26
- 依据：round134–137 里，同一段场景描写（「奈斯站在楼梯阴影里，没有摘风帽」）加上玩家说「奈斯一直盯着我」，模型两次把奈斯定为「看着」、一次定为「未特别注意」；三次引用的依据都是场景描写和 NPC 记录，玩家那句话只是把判断推了一把。用户就此确认：档位的默认答案由规则给，模型只负责有依据的例外，玩家断言别人在不在看不算依据。
- 当前规则：[SPEC 0005 §6.2](../specs/0005-world-facts-and-knowledge.md)。
- 取代范围：[ADR 0059](0059-bystanders-notice-by-passive-perception-and-react-by-their-own-view.md) 第 2 条里「KP 给每个候选人一个注意档位……没有依据时按 0」的分工；§6.2 原文里把「玩家描述的做法」列为档位依据的写法。

## 决定

1. **Rules 先给默认档位。** 正在执行 Activity 的人是「分心」，其余是「在场但未特别注意」。失明、耳聋仍由感官判断处理；「看不到」没有位置事实，规则暂时算不出来，仍由 KP 判。
2. **KP 只列要改档的人，每处改档引用冻结上下文里关于此人的记录**（场景描写与最近事件、此人的状态与身份、光线与遮挡）。填写校验要求每个列出的人至少引用一条记录；Rules 再核对一次：与默认不同而没有依据的档位，整个提案拒绝。
3. **行动者对他人注意力的说法不是依据。** 玩家的意图文本本来就不是可引用条目；提示词不再让模型据此判断。玩家可以描述自己怎么做，不能替 KP 认定别人在不在看。
4. **NPC 状态成为权威事实后接上默认。** [ADR 0061](0061-npcs-move-by-their-own-decision-and-the-table-shows-who-is-present.md) 只带来在场、任期、存活、清醒；等 NPC 的姿态或注意力（宣读、添柴、警觉）也成为权威事实，直接映射成默认档位，模型基本不再需要改档。

## 后果

- 玩家的说法不再影响档位；含糊的场景描写仍可能让模型改档，但只能是引用了具体记录的例外，可以逐条核对。
- 模型只写例外，输出变短；提示词那一段长度相近（v61）。
- 探针每次把各人的档位和依据记入验收结果，跨批次看是否稳定。
