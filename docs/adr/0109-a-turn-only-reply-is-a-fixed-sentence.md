# ADR 0109：只讲轮到谁行动的回复由服务器给固定句子

- 状态：已接受
- 日期：2026-10-05
- 依据：
  - 用户提出"旁白在写的时候就思考"，以替代"审核加思考"。2026-10-05 用 46 份存档旁白请求做了对比（[回执](../agent/receipts/narration-writer-thinking-ab-20261005.md)）：
    - 写时思考与现行写法都是 43/46 通过审核；
    - 写时思考新出三处错，其中一处把轮到谁写错；
    - 每段多约 2.5 秒、约 ¥0.003。

    因此没有采用。
  - 两种写法的编造，都集中在材料只有"轮到谁行动"的回复上：
    - round168："奈斯仍站在守灵夜那边，没有开口"；
    - round170：给奈斯编了一整段台词。

    这种回复不需要模型。用户同意改为服务器给固定句子（"可以，按这个顺序做"）。
- 当前规则：[SPEC 0016 §8.3](../specs/0016-part-c-compound-actions-and-claims.md)
- 取代范围：无。写作与审核的流程（ADR 0069–0071）对其他回复不变。

## 决定

1. **判定。** 按"要讲的说明"判定：只看 `narratedClaimIndices`，提交回执和单纯的结算记录不算。若全部都是 `turnStarted`，回复就是固定句子。
   - 逐条写"轮到某某行动。"，最后一条前加"现在"。
   - 轮到观察者自己时写"你"，其余用说明里给这名观察者的显示名。
   - 缺显示名时不走固定句子，照常交给模型（`fixedTurnNarrationBody`）。
2. **动作层。** 提交后发布、提交前发布和"重试回复"三处，都先判定再决定是否调用模型（`narrateReply`）。固定句子不产生模型调用记录。
3. **Room 校验。**
   - `publishDelivery` 对这类回复只接受这句固定正文，其余正文一律拒绝。
   - 超时收尾的临时回复也先认固定句子，不因缺少调用记录而取消。
   - 其他回复仍须与审核通过的正文一致。

## 影响

- 每次只换手的战斗回复省掉写与审两次调用，约 ¥0.005、约 3 秒。这类回复在战斗中最常见。
- 这类回复不再有措辞变化。
- 本次没有真实调用验证。
