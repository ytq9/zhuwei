# ADR 0157：诱捕打击的命中触发、回合开始伤害与挣脱

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150）。这是第五批：诱捕打击。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（武器命中触发、回合开始伤害、挣脱）。
- 取代范围：无。

## 原因

- 诱捕打击的效果在目录里只是描述（“下一次武器命中触发力量豁免……”），施放时整体被拒。
- Rules 没有“之后某次命中才生效”的效果，没有回合开始时的伤害，也没有用动作挣脱效果的检定；战斗中现有的基础动作里没有挣脱。

## 决定

1. **目录与编译。** 诱捕打击有两个效果：施法者身上的修正 `weaponHitRider`（力量豁免，大型或更大的目标有优势），以及只在命中时施加的束缚状态（`on: "weaponHit"`），后者带回合开始伤害 1d6 穿刺和以力量挣脱。两者都靠专注维持。
2. **命中触发。** 准备武器攻击（非法术攻击、单一目标）时，若攻击者带着触发修正，为目标预留豁免骰，DC 取施法者的法术豁免 DC。命中后结算这次豁免：失败时先按法术定义施加束缚（同一专注、记下挣脱 DC），再结束触发；成功时只结束触发，专注因没有效果可维持而结束。未命中时触发保留。
3. **回合开始伤害。** 回合开始的后续流程里，在躲藏察觉之前，为身上带回合开始伤害的生物请求伤害骰；它若在专注，同批为每个来源预留一次专注豁免骰（SPEC 0012 §10.2：每个伤害来源一次）。
4. **挣脱。** 新的内置动作 `action:break-free`：用一个动作，对自己或 5 尺内被可挣脱效果束缚的生物做写明的属性检定（加值骰照常计入），成功则效果结束。Rules 在基础动作的可用信息里给出可挣脱的目标，读模型据此在行动列表里提供“挣脱”；NPC 的回合选项也列出它。

## 影响

- 诱捕打击可以施放并生效，被束缚者和它的同伴能用动作挣脱。
- 区域外的环境危险、世界交互里的攻击不会触发这类修正。
- 不改持久化结构的外层；效果记录的生命周期多两个可选字段，基础动作的可用信息多一个键。
