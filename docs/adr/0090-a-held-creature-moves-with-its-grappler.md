# ADR 0090：被擒抱的生物随擒抱者移动

- 状态：已接受
- 日期：2026-10-04
- 依据：[round160](../agent/receipts/vnext-round160-validation.md) 中"走到楼梯阴影里，把奈斯拦腰抱起，扛到炉边"检定成功后，旁白写奈斯被扛到炉边，权威状态里奈斯仍在楼梯旁。用户要求修正，并确认 SPEC 0014 §4 的新条款文字："行动者擒抱着的生物随行动者移动，停在行动者身边；遭遇中拖带它时速度减半，除非它比行动者小两级或以上（2014 语义）。"
- 当前规则：[SPEC 0014 §4](../specs/0014-observer-tactical-map-and-environment.md)
- 取代范围：[ADR 0087](0087-the-actor-may-first-walk-within-the-scene.md) 决定 5 中"不搬动、推动或拖动别的生物"的拖动部分。推动（强制移动）仍未实现。

## 决定

1. **遭遇之外。** 行动者在本场景内走动（`CharacterRepositioned`）时，它擒抱着的生物（`conditions.grappledBy` 指向行动者）不挡路，随行动者一起走；走到后停在紧贴行动者的一处空位：在场景内、不与他人占位重叠、与行动者之间没有不可通行物，取离行动者上一个路径点最近的一处（跟在身后），并列时取 y、再取 x 较小的。事件多一个 `carried` 列表，按角色 id 排序记录每个被带着的生物停在哪里；没有擒抱时不写这个字段，与此前的事件逐字节相同。没有空位时这次走动被拒绝（`approach:no-room-for-carried`），交 KP 修订。
2. **遭遇之中。** 擒抱者在自己回合移动（`MovementSegmentCommitted`）时同样带着被擒抱者，每一段结束时按同一规则放在身边，事件同样记 `carried`。只要有一个被擒抱者没有比擒抱者小两级或以上，这段移动的消耗加倍。准备动作触发的移动不带人，擒抱着人时这类移动被拒绝。
3. **重放。** 重放时核对 `carried` 恰好是当时擒抱着的生物，各自的位置合法；被带着的生物不受借机攻击，因为它没有用自己的移动。擒抱关系不因被带着走而改变。
4. **观察者与更正。** 看得见场景的观察者多得到一条 `carriedAlong` 机械结果（谁被带了过去）；更正这次行动时，行动者与被带着的生物的地图位置都恢复。
5. **实现位置。** 放置与校验在 `rules/v2/carry.ts`，场景内走动和遭遇移动共用；体型等级读 `combat-geometry.ts` 的 `entitySizeRank`。

## 影响

- "把奈斯抱起来扛到炉边"在规则上可以表达为：一步对抗检定并写擒抱效果，下一步带 `approach` 走到炉边，奈斯随行。KP 是否这样写，由填写指引和真实调用验证。
- 跨场景移动仍按 SPEC 0006 §7 结束擒抱，不带人离开场景。
