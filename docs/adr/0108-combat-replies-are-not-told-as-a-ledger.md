# ADR 0108：战斗旁白的材料不按账目给

- 状态：已接受
- 日期：2026-10-05
- 依据：
  - 第 168 批真实验证的战斗旁白（[回执](../agent/receipts/vnext-round168-validation.md)）读起来像记账：
    - "奈斯在战斗中先后移动了约3尺、4尺、8尺和14尺"；
    - 闪避照念规则："直到它下个回合开始，它看得见的攻击者对它出手有劣势，它的敏捷豁免有优势"；
    - 躲藏写成"你试着在守灵夜里躲藏起来，动作已经做出"。
  - 第 167 批的开战旁白有一句"开战这一下没有结算任何攻击"。
  - 这些句子都照着写作者收到的材料写，所以改材料，不改提示词。用户要求"把战斗旁白的记账句修了"。
- 当前规则：[SPEC 0016 §8.3](../specs/0016-part-c-compound-actions-and-claims.md)（旁白按冻结说明写）；[SPEC 0014 §4](../specs/0014-observer-tactical-map-and-environment.md)（战斗地图动作的旁白）。条款不变。

## 决定

1. **相邻的移动段合成一条。**
   - 战斗中的移动按段提交，以便借机攻击和预备动作在段与段之间触发。每段仍是一条说明，在它自己那一刻按观察者投影。
   - 投影之后，某个观察者的说明里同一生物紧挨着的几段，合成第一段那一条：距离按各段事件的精确距离相加，依据合并（`mergeAdjacentCombatMoves`）。
   - 中间隔着别的说明（例如一次闪避）就不合。
   - 观察者只看见其中几段时，只合并他看见的。
   - 起初在权威说明里合并。但观察者投影逐个事件取说明，合并后的那条会被投影两次，`claimRef` 重复，一致性检查拒绝，旁白记为欠着（NPC 回合的房间测试发现）。所以改在投影之后合并。
2. **内置动作按看得见的样子说。** `BUILTIN_ACTION_EFFECTS` 不再写规则效果：
   - 疾走："全力向前冲。"
   - 撤离："小心地脱开身，不给对手出手的空档。"
   - 闪避："全神戒备，专心躲闪攻击。"
   - 躲藏："藏起身形，尽量不让人发现。"

   规则效果由动作名和地图状态表示。
3. **开战说明只说开战。** 删去"开战这一下没有结算任何攻击"，只留"战斗开始，各方按先攻轮流行动。"。
4. **写作者不收到回执。** 说明里已有具体结果时，"已提交"回执和单纯的步骤结算本来就不讲。现在写作者的材料里也不再给这两类，审核仍收到全部材料，以便定位。这和 SPEC 0016 §8.3 去掉空社交分组的做法相同。

## 影响

- 观察者的说明条数可能变少，事实不变。
- 冻结请求的形状变了。改版前已冻结、还没写成的旁白，重写时按新材料重建。
- 本次没有真实调用验证；需要一批编号的真实探针。
