# ADR 0093：躲藏与搜索找人

- 状态：已接受
- 日期：2026-10-04
- 依据：[ADR 0092](0092-common-action-scripts.md) 定下的实现顺序里，躲藏与搜索找人排在最后，它们需要新的"谁看不到谁"状态。地图只有几何掩护（半身、四分之三、全掩护），没有光照与阴影。用户确认：对某个观察者，行动者要有四分之三或全掩护才能躲。隐藏范围先选了"对所有生物"，随后在指出它与 [ADR 0063](0063-passive-perception-compares-only-npcs-who-can-sense-the-act.md)（玩家不做被动察觉判定）冲突后，改为守 ADR 0063：只对 NPC 隐藏。
- 当前规则：[SPEC 0004 §4](../specs/0004-kp-and-noncombat-mechanics.md)（躲藏、搜索找人两项）
- 取代范围：无。

## 原因

SPEC 0004 §4 写明躲藏只在"遮蔽、阴影或视线阻挡之后"可用，结果高于某个能看见行动者的生物的被动察觉时，该生物看不到行动者的位置。地图没有阴影，能判断的只有几何掩护和观察者能否看见；门槛定多少会实质改变能躲的地方，由用户定为四分之三或全掩护。被动察觉按 SPEC 0005 §6.2 只由 NPC 判定，躲藏沿用这一点，玩家角色从看得见的情形或自己的察觉得知队友在哪。

## 决定

1. **对谁隐藏。** 只对场景里在场、清醒的 NPC；玩家角色始终看得见躲藏者。对每个 NPC 分别判断：观察者看不见（目盲等），或行动者对它有四分之三或全掩护时，才可能对它隐藏；掩护不足的观察者始终看得见行动者。没有任何观察者满足条件时不能躲藏。
2. **检定。** 躲藏沿用隐蔽检定（SPEC 0005 §6.2）：KP 用 concealedCheck 判敏捷（隐匿），列出主要观察者和被察觉时对方看到什么；常用动作脚本 `hide` 在两个结果里都写躲藏效果。Rules 用检定总值逐个比较这些 NPC（冻结名单里的用冻结门槛，其余用其被动察觉与默认注意档位），记下对谁隐藏和隐匿结果。同一结果里收到以行动者为对象的感官证据的观察者不算被躲过。
3. **看不到位置。** 对某个观察者隐藏时，空间可见性对它返回不可见：它的战术地图、它行动时 KP 能引用的对象、走近的目标和 NPC 自己的视图里都没有行动者。行动者本人照常看到自己。
4. **结束。** 行动者攻击或开口交谈时对所有人结束；某个观察者得到以行动者为对象的感官证据时对它结束；场景里任何人移动后逐对重查掩护，掩护不足且看得见的观察者不再被躲过；行动者离开场景时结束。每次结束都由 Rules 写成事件。
5. **搜索找人。** NPC 的任何一次察觉检定（观察或世界互动），总值不低于某个躲藏者的隐匿结果、且躲藏者正对它隐藏时，躲藏者对它重新可见。玩家角色本来就看得见躲藏者。KP 写的 DC 照常决定该次检定的其他结果；这一比较是固定的，所以搜索找人不另设脚本种类。
6. **范围。** 先做遭遇之外；战斗中的躲藏动作与看不见的攻击者的优势另行处理。

## 影响

- 隐藏状态记在行动者的战斗实体上，空间可见性的各个消费者随之过滤。
- 填写表单的常用动作多一个 `hide`，请求体积按实测告知后接受（ADR 0057）。
- 是否稳定由真实调用验证。
