# ADR 0099：帮助与预备的入口

- 状态：已接受
- 日期：2026-10-04
- 依据：ADR 0092 把帮助与预备留待详细讨论。用户确认：帮助按 SRD 5.1 做成战斗动作，遭遇外也做成常用动作脚本；预备的规则层已有（SPEC 0012 §8.1），补地图入口，触发时问玩家用不用。
- 当前规则：[SPEC 0004 §4](../specs/0004-kp-and-noncombat-mechanics.md)（帮助）；[SPEC 0012 §6.3](../specs/0012-authoritative-combat-mechanics.md)（Help）；[SPEC 0012 §8.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（Ready）
- 取代范围：无。

## 决定

1. **遭遇中的帮助（SRD 5.1）。** 一个动作，选一名同伴：它下一次属性检定有优势；或选一个离帮助者 5 尺内的敌人，同伴在帮助者下回合开始前第一次攻击它时有优势。优势记在同伴身上，用掉或到时即失效。
2. **遭遇外的帮助。** 常用动作 `help`：KP 判断能否帮得上，帮得上时同伴下一次与此事相关的检定有优势。
3. **预备。** 战斗地图加预备入口：选触发的生物与事件、选要做的动作；触发时提示玩家执行或放弃（用反应）。NPC 的预备与触发由 NPC 自己决定。

## 影响

- 战斗读模型与地图多两个按钮；KP 表单的常用动作多一个 `help`，请求体积按实测告知后接受（ADR 0057）。
