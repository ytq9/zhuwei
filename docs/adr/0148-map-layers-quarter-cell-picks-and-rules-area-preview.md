# ADR 0148：地图分层绘制、四分之一格选点与 Rules 的射程和范围预览

- 状态：已接受
- 日期：2026-10-11
- 依据：用户要求"得让玩家知道能影响什么"，指出战术地图看不出环境（石墙太短、拉杆太大），要求选点允许最小四分之一格、环境按合理的顺序叠在地图上，并由我来优化地图的表现形式。
- 当前规则：条款不变。[SPEC 0014 §2.1](../specs/0014-observer-tactical-map-and-environment.md)（显示方格与吸附只属于 Adapter）、§§6、7（预览只投影 Viewer 已知的内容，不泄露隐藏目标与隐藏障碍）、§8（地图不自己计算距离、掩护、区域目标或预览）。
- 取代范围：无。

## 原因

- 地图把每个环境要素画成半透明方框，按编号叠放；持续区域画在要素下面；名字和掩护标记画在各自要素里，会被后画的大块地形或人物盖住。
- 页面预览用的测试夹具把墙、木箱、拉杆、门和碎石坡都画成 5×10 尺的同样方块，所以墙显得短、拉杆显得大。模组数据本身的尺寸是对的，例如黑橡木的矮石墙 1×25 尺、灵前烛台 2.5×2.5 尺。Rules 和 KP 生成的几何都按整数英寸，没有整格限制。
- 选点按整格（5 尺）吸附，站不到 2.5 尺物件旁边。
- SPEC 0014 §7 的预览一直没有实现，`preview` 恒为 null。地图只能画示意圈，玩家看不出法术会碰到谁，也看不出目标在不在射程内。§8 不允许地图自己算这些。

## 决定

1. **分层绘制。** 自下而上：地面与网格、地面类要素（地形、沟、水、台阶）、物件（可互动物、可破坏物）、墙与门（屏障、门、矮墙、崖壁）、持续区域、能力示意（射程圈、范围图形）、人物、名字与掩护标记、玩家的选点。同一层里面积大的画在下面。墙画成实心石纹，木料画木纹，金属画栅纹；关着的门画出门板，上锁的再画门闩；可破坏物画交叉撑；泥地、碎石各有纹理；材质决定颜色。每个要素的名字放得下才显示，选中的总是显示。文字和标记随地图尺寸缩放。持续区域只在边线和名字上响应点击，区域里的门仍可点选。
2. **四分之一格选点。** 点地图选点按四分之一格吸附，即半格边长 2.5 尺（30 英寸）；方向键每次移动一格，按住 Shift 移动四分之一格；目的地和光标按玩家自身占位的大小画出。这只是显示吸附（§2.1），Rules 照收任意整数英寸。
3. **单体目标的射程。** Rules 在 `combatControls` 里为每个以生物为目标的能力列出：玩家看得见的生物中在触及或普通射程内的（`withinRefs`），只在远射程内的（`longRangeRefs`，攻击有劣势）。测距与攻击时同一函数。擒抱、推撞等 5 尺动作用 `withinFiveFeetRefs`。看不见的生物不是候选。地图和目标列表据此标出；自己回合里够不着的生物不能选；遭遇之外照样标出但不拦，句子仍交 KP。
4. **区域预览。** 选好区域的原点（以及立方、锥形、线形的方向）后，页面经桌面接口 `previewArea`、Room 的 `previewTacticalArea`，用 `project(viewer, { tacticalAreaPreview })` 向 Rules 要预览。Rules 只用玩家地图上的生物和已知要素计算：范围内看得见的生物（`knownAffectedEntityIds`）、自己是否在内（`knownSelfEffects`）、在内的盟友、原点被哪堵已知的墙挡住以及停在哪。看不见的生物和未发现的墙不参与，所以两个只在这些上不同的世界得到逐字节相同的答复；真正施放时 Rules 仍对完整世界重算（§5）。预览只读，不写事件、不改状态。
5. **预览形状。** `TacticalPreview` 的 `area` 形状增加 `abilityRef` 与 `knownAffectedEntityIds`，球形时省略 `direction`。

## 影响

- 不改产品条款、持久化结构或事件。`combatControls` 新增 `withinFiveFeetRefs` 和各能力的 `targetsInRange`，它们在 `controlledCharacter` 之外，不进入旁白写手的材料。
- 新增只读接口 `previewArea`，每选好一个区域请求一次，同一空间版本内相同的选择不重复请求。
- 当前角色编译只把球形区域法术（例如云雾术）作为结构化能力提供；立方、锥形、线形的区域法术还不在行动列表里，它们的预览目前只在定向测试中经过。
- Rules 的区域计算把与区域相交的施法者本人也算在内。以施法者位置为原点的立方或锥形会因此包含施法者；这类法术进入行动列表前需要另行确认原点的取法。
