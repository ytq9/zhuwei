# ADR 0045：提案只带中文写作要求，不带审核标准

- 状态：已接受
- 日期：2026-09-24
- 依据：中文表达指引是旁白生成、旁白审核和提案三处共用的一段文字。其中后三段是审核者的判断标准，例如“presentation仍须fail并报PRESENTATION”“不因审查者自己的文风偏好……拒绝”。2026-09-14 起，这段文字整体放进提案的 authority 指引，提案模型每次填写都带着这三段，约 330 个估算 token。提案模型写 NPC 台词和摘要，但不审核任何东西。
- 当前规则：[SPEC 0016 §8.3](../specs/0016-part-c-compound-actions-and-claims.md)（自然表达可以润色句法，不能改写冻结事实与来源语义；条款不变）
- 取代范围：提案 authority 指引中整段引用中文表达指引的做法。旁白生成与审核的文字不变。

## 决定

1. 中文表达指引分成写作部分（前两段：怎么写、怎么转述有病句的原材料）和审核部分（后三段）。两部分按原顺序拼起来仍是原来的整段文字，旁白使用的文字逐字不变。
2. 提案 authority 指引只用写作部分。提案需要的写作规则，包括不写“付酬”这类刻意书面用词，都在写作部分里。
3. 指引 v45。按能力的请求体积各降 329 个估算 token（[ADR 0035](0035-ratchet-the-vnext-proposal-request-size.md)）。工作流 hash 变化，未完成的工作按 [ADR 0038](0038-reask-unfinished-work-after-a-version-change.md) 重问。

## 后果

- 提案模型不再读到审核者的判断标准。NPC 台词的写法仍由写作部分约束，并由旁白审核把关。
