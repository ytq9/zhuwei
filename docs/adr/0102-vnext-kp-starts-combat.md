# ADR 0102：新版 KP 开战

- 状态：已接受
- 日期：2026-10-05
- 依据：第 166 批真实验证中，玩家说"我拔出长剑，冲向奈斯并挥剑攻击他。"，新版 KP 无法进入先攻与回合：Rules 的开战输入只有旧版 KP 的复合动作会触发，世界互动的攻击只打地图要素。用户决定按已批准的规则补上开战。
- 当前规则：[SPEC 0012 §§3、5](../specs/0012-authoritative-combat-mechanics.md)；NPC 的机械定义见 [SPEC 0006 §§3、8](../specs/0006-module-npc-and-faction-protocol.md)。
- 取代范围：无。

## 决定

1. **开战表单。** 新增按需加载的表单 `startCombat`，填写为 `decision.kind = "startCombat"`。
   - 对场景中在场生物的敌对行为（遭遇之外）用它开战。KP 写参战者、谁敌对谁、每名参战者是否被突袭及依据，以及一句开场描述。
   - 开战这一步不结算攻击。Rules 掷先攻：玩家掷自己的先攻，NPC 由房间掷。随后按先攻顺序轮到谁谁行动。
   - 选它是为了只在选中时加载表单；做成常驻的决定种类，每次填写都会带上它的结构。
2. **突袭。** 只有当所有敌对它的参战者都在躲藏、且隐匿总值不低于它的被动察觉时，一个参战者才能被突袭。降级时以可修订的诊断检查，Rules 也检查。
3. **NPC 的初次战斗属性。** 模组 NPC 在地图上只有身体，没有 HP、AC 和攻击。按 SPEC 0006，NPC 第一次产生机械作用时由 KP 固定其定义：表单为尚无战斗属性的参战 NPC 带上 `combatStatistics`，内容是 HP、死亡策略和攻击（近战、远程或带伤害的豁免）。能力值、熟练加值和身体沿用已有记录；AC 与速度须与已记录的装备一致。冻结上下文为当前场景中尚无战斗属性的 NPC 附上模组原文的战斗属性行，供 KP 参照。
4. **加入进行中的遭遇（SPEC 0012 §3.4）。** 敌对行为的对象已在交战时，同一表单让新参战者加入：
   - 新参战者掷先攻，按总值插入当前顺序；同值排在后面。
   - 若它的顺位本轮已过，从下一轮开始行动。
   - 加入不产生突袭；有待回答的战斗选择时不能加入。
5. **说明与旁白。** 遭遇开始带上 KP 的开场描述，生成开战、参战者与是否被突袭、先攻顺序的说明。
6. **指引。** 世界互动的说明写明"攻击只打地图要素"；在遭遇之外对生物动手用 `startCombat`；遭遇中的攻击用能力操作或地图动作。

## 影响

- 请求体积：
  - 新增 `startCombat` 选择（5636 token）；
  - 含世界互动的选择各 +34；
  - 全部选择 +1507；
  - 选表请求 +424；
  - 大厅中冻结上下文约 +206（三名 NPC 的属性行）。
  - 已按 ADR 0057 告知并接受。
- 奈斯已记录的装备算出 AC 11，模组原文为 AC 13，需在模组数据中补上护甲。
- 玩家与 NPC 先攻同值时仍问玩家，与 SPEC 0012 §5.2"由 KP 定"不一致，未处理。
