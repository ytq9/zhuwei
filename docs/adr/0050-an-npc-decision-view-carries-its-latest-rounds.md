# ADR 0050：NPC 决策视图只带最近六轮的原话、对话和所见

- 状态：已接受
- 日期：2026-09-25
- 依据：NPC 决策视图收着这个 NPC 说过和听过的每句原话、每段对话、每条所见事实。每次和她交谈，提交的计划里都带着这份视图，交谈事件也把它存进事件日志。本地预览那一桌，莉安的视图每轮约多 6,500 字节，四轮交谈的事件依次是 21K、29K、38K、44K、53K 字节，事件日志按对话轮数的平方增长。规则在房间载入、归档恢复和历史分支重放时，会逐个用当前代码重建视图并与事件里存的逐字比对。用户同意让冻结内容不再随房间增长（“可以”，承接 [ADR 0049](0049-an-npc-decision-view-has-its-own-ceiling.md) 所说的下一步）。[SPEC 0006 §4](../specs/0006-module-npc-and-faction-protocol.md) 规定 NPC 投影只提供她“知道、感知或合理记得的事实”，[SPEC 0016 §4.2](../specs/0016-coarse-forms-frozen-adjudication-context-and-typed-claims.md) 要求相关 NPC 的有限知识，都没有要求把她的全部记录放进决策依据。
- 当前规则：[SPEC 0016 §4.2](../specs/0016-coarse-forms-frozen-adjudication-context-and-typed-claims.md)、[SPEC 0006 §4](../specs/0006-module-npc-and-faction-protocol.md)（条款不变）
- 取代范围：新行动冻结 vnext-1 完整视图的做法；[ADR 0048](0048-each-character-carries-its-latest-six-rounds.md) 第 5 条里“调取后原话记录和对话记录一起回来”这一部分；知识选择 vnext-4 的轮次算法。

## 决定

1. NPC 决策视图改为 vnext-2：原话、对话和所见事实三类记录，只保留这个 NPC 最近六轮的，以及不属于任何一轮的（开局就有的、她没有对应记忆的）。其余记录、她持有的完整记忆目录和知识目录都不变。
2. 一轮是她在游戏中感知到、听到或推断出某件事的一个故事内时刻。故事交给她的世界事实算背景，不算一轮，所以同一次行动里写进故事事实不会让窗口前移。规则和知识选择器用同一个函数（`recentMemoryRounds`）数轮次；知识选择改为 vnext-5，故事给的世界事实按话题带。
3. 新行动冻结 vnext-2。规则按被核对的视图自己的版本重建：事件和计划里存的是 vnext-1 的，照旧按完整视图逐字核对，每次重放都一样；vnext-2 的按最近六轮核对。
4. 故事事实给 NPC 写记忆时，依据可以是她完整视图里的任何记录，读取集必须覆盖她当前的视图。这样部署前已冻结的旧计划仍能提交。

## 后果

- 同一个 NPC 连续交谈 16 轮（测试数据）：第 7 轮以后，视图每轮多约 1,750 字节，原来约 5,000；交谈事件每轮多约 2,350 字节，原来约 6,400。第 16 轮时视图 48,299 字节，完整视图是 77,665。
- 调回一条旧记忆，会带回它的原文和感知事实，但不会带回那一轮的原话记录（含她当时的动机）和对话记录。
- 还在增长的：视图里的完整记忆目录和知识目录（每条记忆约 580 字节）、冻结上下文里的全部记忆正文和感知事实，以及每次行动存的 KP 世界投影。这是接下来的工作。
- 同一次行动里，前面的步骤让交谈对象获得新记忆时，交谈核对照旧会失败，与 vnext-1 相同。
