# ADR 0153：猎人印记的额外伤害随武器伤害一起掷

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150）。这是第二批的第二步之二：猎人印记。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（猎人印记）。
- 取代范围：无。

## 原因

- 猎人印记的效果在目录里只是描述（“武器命中额外 1d6；追踪检定优势”），施放时整体被拒。
- 伤害骰按能力定义的伤害组成请求和结算，没有“只在攻击某个目标时多一枚骰子”的入口。

## 决定

1. **目录。** 猎人印记的修正是 `weaponDamageDieFromSource`（d6），记录在被标记者身上，来源是施法者，靠专注维持。
2. **伤害。** 准备一次攻击时，若这是武器攻击（不是法术攻击），对每个被攻击者自己标记过的目标，冻结一项额外伤害：1d6，类型取武器的第一种伤害。它并入那个目标的伤害组成一起请求，所以重击时随武器伤害骰一起翻倍。单目标攻击、多目标攻击、护盾术延后结算的伤害和借机攻击都走这一处。
3. **察觉。** 躲藏察觉中，察觉者对自己标记的躲藏者掷骰时具有优势。

## 影响

- 猎人印记可以施放并生效。
- 尚未实现：被标记者降到 0 生命值后，施法者在之后的回合用附赠动作把印记转给新的生物。这需要一个只在特定时机合法的动作；在投影的改动确定之前，没有办法保证它不常驻在行动列表里。KP 裁定的生存与察觉检定（世界交互）也还不计这项优势。
- 不改持久化结构；攻击的冻结机械结果在有印记时多一个可选字段 `markDamage`。
