# 0.4 开发重置：放弃 0.4 以前的房间与可恢复归档

- 状态：已接受（用户于 2026-08-31 明确确认）
- 日期：2026-08-31
- 关联规格：SPEC 0006、SPEC 0013、SPEC 0015
- 取代范围：只取代各 SPEC/ADR 中要求保留、迁移或恢复前 0.4 房间的条款
- 规则所在：[SPEC 0013 §0.4](../specs/0013-versioned-runtime-profiles.md)

## 背景

0.4 之前的房间绑定的是已经退役的 Profile 与事件 schema。为它们保留 Adapter、fallback 与 migration，会让每一次 Profile 演进都要同时满足一份没有真实用户的历史契约，成本随代际累积。

## 决策

放弃全部 0.4 以前的房间及其可恢复归档。当前生产树不保留它们的 Adapter、fallback 或 migration；未来兼容必须另行裁定，不由本决定顺延。

## 影响

机械、权限、秘密、单一权威与 fail-closed 合同不受影响——本决定只收走"必须能读回旧房"这一项义务。精确取代清单与当前 Profile 闭包由 SPEC 0013 §0.4 给出；SPEC 0006 的旧房保留段由该节窄取代，两份规格的 frontmatter 互相记录了这条取代关系。
