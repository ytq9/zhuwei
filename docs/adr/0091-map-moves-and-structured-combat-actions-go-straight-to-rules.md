# ADR 0091：地图移动与战斗中的结构化动作直接交给 Rules

- 状态：已接受
- 日期：2026-10-04
- 依据：用户要求补全战术地图："让人物位置关系对应正确，并可以在地图上移动，使用常用动作，施法等"。用户对四个问题的选择：遭遇之外点地图移动"直接移动，不调模型"；战斗中自己回合用地图和按钮做的动作"直接结算后写一句旁白"；遭遇之外从地图选法术或攻击并点目标"交给 KP 裁定"；并确认 SPEC 0014 §§3、4 的新句："地图移动、结束回合和战斗中的结构化动作由 Room 直接交给 Rules，不经 KP。"
- 当前规则：[SPEC 0014 §§3、4](../specs/0014-observer-tactical-map-and-environment.md)
- 取代范围：无。此前遭遇中的 `movement` 与 `combatEndTurn` 已是直接输入，本决定把它写进规格并扩展到遭遇之外的地图移动。

## 原因

地图此前只能查看：遭遇中的 `movement` 输入存在但没有命令和界面发送它；施法与职业能力的按钮变成一句话交给 KP，每次至少两三次模型调用；遭遇之外玩家只能靠 KP 写的 `approach` 改变位置。点一下地图就要等模型裁定、为走几步写旁白，代价和延迟都不必要。

## 决定

1. **遭遇之外的地图移动。** 新 Room 输入 `mapMove`（当前空间版本 + 目的地：地图上一点，或某人、某物旁），按 ADR 0087 的同一找路规则交给新 Rules 输入 `repositionCharacter`，提交 `CharacterRepositioned`；擒抱着的生物随行（ADR 0090）。不调模型、不写旁白、不推进虚构时间；准备和提交时各核对一次空间版本。走不到时只说"现在走不到那里"，不区分原因，隐藏障碍不因此暴露。遭遇中改用回合内移动。
2. **战斗中的结构化动作。** 移动、结束回合，以及在自己回合用地图和按钮做的攻击、施法、基础动作，由 Room 直接交给 Rules 结算，不经 KP 裁定；结算后由模型就已提交的结果写一句旁白（另立条款，用户确认文字后实施）。
3. **遭遇之外的施法与攻击。** 从地图选好的法术或攻击与目标，作为明确的玩家意图交给 KP 裁定，KP 决定后果（是否开战、NPC 的反应）并写旁白。

## 影响

- 第 1 条已实现（Room、Rules、API 与地图界面分步提交）；第 2、3 条按后续提交实施，未实施的部分在回执里列为未覆盖。
- 走动不推进时间，所以地图上来回走动不会让 NPC 的计划提前到期。
