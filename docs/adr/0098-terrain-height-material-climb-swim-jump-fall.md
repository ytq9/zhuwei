# ADR 0098：地形高度与材质，攀爬、游泳、跳高与坠落

- 状态：已接受
- 日期：2026-10-04
- 依据：用户要求"加入其他高度的地形，沟也可以爬下去再爬上来，得看具体高度和材质，程序内记录地图中的地形信息，KP 用到时给 KP 这些状态。加入跳跃机制和攀爬机制，具体的数值去查 D&D 规则"，并要求一并加入游泳。按 SRD 5.1 拟写的 SPEC 0014 §4 条款经用户确认，取代原文"攀爬与游泳涉及高程，暂不提供"。
- 当前规则：[SPEC 0014 §4](../specs/0014-observer-tactical-map-and-environment.md)
- 取代范围：SPEC 0014 §4 原文"攀爬与游泳涉及高程，暂不提供"。

## 决定

1. **地图记录地形。** 地图要素带高度与材质；新增沟（向下的深度）、台阶、矮墙、崖壁与水域。KP 用到某处时，冻结上下文里给出这些状态。
2. **数值按 SRD 5.1。** 攀爬与游泳每尺多花 1 尺移动（有对应速度时不多花），难攀的表面与难游的水需运动检定，DC 由 KP 按材质定，失败不前进或坠落；跳高有 10 尺助跑时最高 3 + 力量调整值尺，原地减半；坠落每 10 尺 1d6 钝击，最多 20d6，落地倒地。
3. **沟。** 可跳过（ADR 0092 的跳远），也可按深度与材质爬下再爬上。
4. **遭遇内外。** 遭遇外由常用动作脚本执行；战斗地图同样可以跳、爬与游，按移动扣除。
5. **新地图内容。** 黑橡模组的新版地图加入沟等地形，已有房间保持原版本。

## 影响

- 地图引擎要处理高度差、爬上爬下与坠落，是本组里最大的一项，按数据层、遭遇外脚本、战斗移动三步实现。
