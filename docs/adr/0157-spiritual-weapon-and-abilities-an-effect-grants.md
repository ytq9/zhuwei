# ADR 0157：灵体武器，以及效果持续期间授予的动作

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150），并同意修改投影。这是第四批：灵体武器。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（召唤物、效果授予的动作）。
- 取代范围：无。

## 原因

- 灵体武器的效果在目录里只是描述（“每回合可用附赠动作移动 20 尺并再次攻击”），施放时整体被拒。
- Rules 没有“因为某个效果还在，所以多出一个动作”的机制。行动列表就是战斗实体的 `abilityRefs`；角色同步会用编译结果整体覆盖它，临时塞进去的动作会丢。
- 施放时的攻击按法术射程编成远程攻击，施法者身边有敌人时会吃到远程劣势；SRD 写的是从武器处发起的近战法术攻击。

## 决定

1. **召唤物。** 新的区域种类 `spectralWeapon`：施放时出现在第一个被攻击的生物身边（占 5 尺空间），持续时间取自法术，不靠专注。区域定义带 `grants`，列出它授予施法者的动作。
2. **授予的动作。** 法术编译时同时编译并登记伴随能力（灵体武器的“打击”：附赠动作，同样的法术攻击和伤害），但不放进常驻的 `abilityRefs`。施法者有一个仍然持续、授予该动作的区域时，投影把它列进行动列表，`invokeAbility` 也接受它；区域结束后两者都不再接受。
3. **从召唤物处量起。** 伴随能力的目标带 `fromZoneOf`：射程、触及和掩护从召唤物的 5 尺空间量起，触及为移动距离加触及距离（20 尺 + 5 尺）。攻击之后召唤物移到目标身边，记为新事件 `EffectZoneMoved`（只记账，由攻击本身叙述）。施放时的攻击按触及编译（法术射程加 5 尺），是近战法术攻击。
4. **旁白依据。** 新增覆盖测试：以地图动作的根（`combat-act:`）走完各批法术的施放、重复豁免、加值骰、区域形成与消失、召唤物移动、援助术提高生命值，每个根都能从依据完整叙述。

## 影响

- 灵体武器可以施放，之后的回合可以用附赠动作再次攻击，地图画出它的位置（区域标签“灵体武器”）。
- 猎人印记的“转移印记”可以沿用同一机制，尚未做。
- 不改持久化结构的外层；区域记录多一个可选字段，新增一个事件类型。
