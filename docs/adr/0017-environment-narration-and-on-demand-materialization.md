# 环境描写先成为叙述承诺，按需固化

- 状态：已接受（用户于 2026-09-05 明确批准）
- 日期：2026-09-05
- 关联规格：SPEC 0001、SPEC 0016
- 取代范围：取代"首次描写即完整固化"与"禁止一切新环境描写"两项限制
- 来源提案：[环境描写与按需固化](../agent/narrative-detail-contract-proposal.md)
- 规则所在：[SPEC 0001 §§3.3、7、12](../specs/0001-llm-kp-responsibility-contract.md)、[SPEC 0016 §8](../specs/0016-coarse-forms-frozen-adjudication-context-and-typed-claims.md)

## 背景

要求 KP 在第一次描写时就把每个环境细节完整固化为权威事实，会让一句氛围描写背上机械对象的全部代价；反过来禁止 KP 新增环境描写，则让世界失去可被利用的质感。两端都不对。

## 决策

KP 可以先描写非机械环境细节并保存为叙述承诺。玩家引用、调查、利用，或该细节产生因果/机械影响之前，按原描述固化。跨场景、恢复与重试保持连续性。

## 影响

叙述承诺只约束连续性，不直接成为机械对象或裁决结果；秘密、机械与单一 Room 权威不变。规则文本在上述条款，本 ADR 不重复。实现与在线验收独立记账，批准不等于验收通过。
