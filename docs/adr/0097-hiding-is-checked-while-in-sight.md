# ADR 0097：躲藏改为视线内定期察觉

- 状态：已接受
- 日期：2026-10-04
- 依据：用户要求 NPC 也能对玩家躲藏，并给出规则："只要出现在视线内就每回合进行察觉检定，如果在 NPC 回合内走进玩家的视野中时，也要进行一次察觉判定……完全掩体视为不在视线内，其他的掩体按照加值进行察觉判定"，"对所有人都是这样"。按此拟写的 SPEC 0004 §4 条款经用户确认，掩护加值沿用 ADR 0094 那组。战斗中攻击躲藏者，用户要求按 D&D 规则。
- 当前规则：[SPEC 0004 §4](../specs/0004-kp-and-noncombat-mechanics.md)（躲藏、搜索找人）；[SPEC 0012 §6.3](../specs/0012-authoritative-combat-mechanics.md)（Hide、Search）
- 取代范围：[ADR 0093](0093-hide-and-search.md) 决定 1（只对 NPC）、4（结束方式）、5（搜索只对搜索者生效）、6（遭遇中另行处理）；[ADR 0094](0094-hide-dc-follows-cover.md) 决定 1、2（按被动察觉一次性比较、移动后按 DC 重算）。掩护调整值（无掩护 +5、半身 +2、四分之三 +0）保留，全掩护视为不在视线内。

## 原因

ADR 0093/0094 只在躲藏当时和移动后用被动察觉比较，而且按 ADR 0063 只有 NPC 参与比较，NPC 无法对玩家躲藏。用户的规则让双方对称：在视线内的人会不断有机会察觉，一被发现就对所有人暴露。这是产品规则，不是 SRD 原文（SPEC 0012 §2 要求如此标明）。

## 决定

1. **谁躲谁。** 玩家躲 NPC，NPC 躲玩家。隐匿结果在躲藏时掷定。
2. **何时比较。** 对每个能看到躲藏者的对方（躲藏者不在它的全掩护后、它没有目盲）：遭遇中在它每轮回合开始时，以及躲藏者在它的回合内走进它的视线时；遭遇外每有一次行动提交。由服务器替它掷察觉，这是主动检定，不是 ADR 0063 所说的被动察觉。
3. **何时发现。** 察觉结果加掩护调整不低于隐匿结果即发现，躲藏对所有人结束。搜索找人同此。躲藏者攻击或出声时也结束。
4. **攻击看不见的对象（SRD 5.1）。** 看不见目标的一方攻击时有劣势，并须猜一个位置，猜错自动落空；看不见攻击者的一方被攻击时，攻击者有优势。躲藏者攻击后，无论命中与否都暴露。
5. **遭遇中。** 地图提供躲藏与搜索动作（SPEC 0012 §6.3），用同一规则。

## 影响

- 躲藏状态不再按观察者逐个记录，而是一个"正躲着"的状态加隐匿结果；空间可见性对所有对方隐藏。
- 每次比较会产生服务器掷骰。
