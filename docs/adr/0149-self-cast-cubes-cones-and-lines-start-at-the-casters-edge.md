# ADR 0149：立方、锥形、线形法术进入行动列表，从施法者自身发出的从其占位边缘展开

- 状态：已接受
- 日期：2026-10-11
- 依据：用户要求把立方、锥形、线形法术也加进行动列表；对"从施法者自身发出的立方、锥形、线形从哪里开始"选择了"从施法者身边开始"，并同意为此修改验收门的期望。
- 当前规则：[SPEC 0013 §5.6](../specs/0013-part-b-ability-and-geometry.md)（自身区域的原点）、[SPEC 0012 §9.4](../specs/0012-part-b-abilities-damage-and-conclusion.md)（豁免失败时推开）。[SPEC 0012 §4.2](../specs/0012-authoritative-combat-mechanics.md) 与 ADR 0029 的"区域按几何包含施法者与盟友"不变。
- 取代范围：SPEC 0012/0013 几何验收门中"立方、锥形、线形从施法者位置施放时施法者也在其中"的期望。

## 原因

- 角色编译只把球形区域法术变成结构化能力，雷鸣波（15 尺立方）、燃烧之手（15 尺锥形）、蛛网术（20 尺立方）都不在行动列表里。
- "自身"射程编成 `rangeInches: "0"`，而 Rules 用"距施法者 0 英寸内"检查原点，施法者脚下的点永远不在其测距核心内，这类区域根本施放不出去。
- 即使施放成功，原点在施法者中心，立方和锥形会覆盖施法者自己的半个占位。按几何判定，施法者会被自己的雷鸣波伤到、推开。SRD 5.1 写的是区域"originating from you"，施法者在区域的起点上，而不在区域里。
- 法术条目里的附带效果（雷鸣波的推开、蛛网术的束缚与困难地形）在 Rules 里没有执行器，带着它们的能力在施放时会被整体拒绝。

## 决定

1. **编译。** 法术区域按形状编译：球形给半径，立方给边长，锥形给长度，线形给长度和宽度（法术没写宽度时为 5 尺）。立方、锥形、线形法术只有在每个附带效果都能执行时才编译——没有附带效果，或是豁免失败时推开；其余（目前是蛛网术）等对应机械做好后再加入。已在列表里的球形法术不变。
2. **自身区域的原点。** 射程缺省或为 0 的区域，调用者提交的原点必须是施法者的位置。立方、锥形、线形从所选方向沿地面离开施法者占位的边缘点展开，高度取施法者所在高度；球形、圆柱仍以施法者位置为原点。是否在区域内仍只按几何判定。地图示意与 Rules 预览用同一起点。
3. **豁免失败时推开。** 法术效果 `push-N`（雷鸣波为 10 尺）在伤害之后，按目标顺序把豁免失败的生物从施法者处沿中心连线推开，按 5 尺一步停在最远的空位；`CreaturePushed` 事件带 `distanceInches`，回放按同一距离重算落点。推撞仍是 5 尺，事件不带该字段。
4. **页面。** 行动列表按形状写明范围（"15 尺立方 · 从你身边发出，再点方向"）；遭遇之外瞄准某人时，从自身发出的立方、锥形、线形朝那个人预览。

## 影响

- 几何验收门的五种区域用例：施法者从自己位置朝 −x 施放的立方、锥形、线形不再包含她本人，也不再包含她身旁的哨兵和鲍勃；球形和圆柱的期望不变。地图测试里立方示意的起点从施法者中心移到占位边缘。
- 现有法术目录没有线形法术，线形只走通了几何与预览，没有真实法术样例。
- 已在列表里的部分球形法术（如云雾术、沉默术）也带着没有执行器的附带效果，施放时同样会被拒绝；本次未处理。
- 不改持久化结构。`CreaturePushed` 新增可选字段，旧事件照常回放。
