# ADR 0151：法术写明的数值修正由 Rules 施加，读进同一有效值来源

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150）。这是第二批的第一步：信仰护盾、法师护甲、冷冻射线、电爪、导引箭、援助术。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（数值修正、同种不叠加、“下次回合结束”的含义）。
- 取代范围：无。

## 原因

- 这六个法术的效果在目录里只是描述（“AC +2”“速度 −10 尺”），Rules 没有执行器，施放时整体被拒。
- SPEC 0012 §10.1 要求 AC、速度、优势和资源的投影与机械读取同一有效值来源。现有的 AC 只读护盾术一种效果，速度只读状态，反应只看回合内是否用过。
- 回合边界持续时间的旁白写的是“持续至……的下次回合结束”，但到期锚点在主体自己的回合内创建时，取的是当前回合的结束。导引箭“直到你的下个回合结束”会在施法者自己的回合结束时就失效。

## 决定

1. **目录。** 法术效果新增结构化字段 `modifier`，写明修正种类；数值取效果的 `value`（按施放环位）。编译按这个字段通用地生成 `grantModifier`，不按法术名分支。法师护甲写“目标穿上护甲时结束”，导引箭写“目标被攻击时结束”。
2. **记录。** 修正效果使用独立的记录类型 `zhuwei.modifier-effect/v1`，与状态效果共用持续时间、到期、专注维持和提前结束的逻辑。状态效果记录的形状不变，旧读者看不到新记录的字段。
3. **有效值。** 新模块 `effect-modifiers` 是唯一的派生来源：攻击检定所对的 AC（法师护甲的基础 AC 只在未穿身体护甲时生效，取较高者；再加护盾术与 AC 加值）、速度（减半之后再加减，不低于 0；被擒抱或束缚时不受加值）、能否使用反应、针对目标的攻击是否有优势、生命值上限的提高。同一种修正不叠加，取最强的加值和最强的减值。
4. **用掉与结束。** 针对目标的下一次攻击检定（不论命中）结束导引箭的优势。目标穿上身体护甲时法师护甲结束，在每个事件之后检查；目标穿着护甲时施放法师护甲被拒，不扣法术位。
5. **援助术。** 生命值上限的提高并入现有的状态同步：上限提高时当前生命值增加同样的量，同步事件带 `raisedWithMaximum` 标记，回放据此复算；效果结束时上限回落，当前生命值不超过新上限。只对有角色档案的生物生效。
6. **回合边界。** 持续到“下次回合结束”的效果若在主体自己的回合内开始，到它下一个回合结束时才到期。只改效果的到期计算；护盾术和预备动作仍用原锚点。
7. **遭遇中的目标。** 沿用 ADR 0150：非伤害能力可以指向任何生物，所以信仰护盾、法师护甲、援助术可以施放于自己和盟友。

## 影响

- 这六个法术可以施放。祝福术、神导术、猎人印记（骰子加值）留在第二批的第二步；区域、召唤、诱捕打击、命令术在后续批次。
- 角色栏显示的 AC 仍取装备算出的值，没有计入法术修正。要满足 SPEC 0012 §10.1 的“投影读取同一来源”，需要投影改读 `effect-modifiers`，这部分在 `projector.ts`，本次没有改。
- 援助术对只有战斗实体、没有角色档案的生物不提高生命值。
- 不改持久化结构的外层；`ConditionStateSynchronized` 多一个可选字段，旧事件照常回放。
