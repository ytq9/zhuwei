# ADR 0154：云雾术与沉默术的持续区域，以及法术成分

- 状态：已接受
- 日期：2026-10-11
- 依据：用户选择为施放必被拒的法术补上执行器（见 ADR 0150）。这是第三批：云雾术、沉默术。
- 当前规则：[SPEC 0012 §10.1](../specs/0012-part-b-abilities-damage-and-conclusion.md)（持续区域）、§9.2（施法验证成分）。实现 [SPEC 0014 §9.3](../specs/0014-observer-tactical-map-and-environment.md)“至少一个能力创建可回放的持续区域”。
- 取代范围：无。

## 原因

- 云雾术、沉默术的效果在目录里只是描述（“重度遮掩浓雾”“区域无声……”），施放时整体被拒。
- Rules 没有能力创建的区域：战斗运行状态里只有效果记录可以存放持续数据。也没有“遮蔽”的概念，视线只看状态（目盲、隐形）、躲藏和全掩护。
- 法术目录没有成分数据，施法验证从不检查言语成分；SPEC 0012 §9.2 要求验证成分。

## 决定

1. **区域记录。** 新的持续效果记录 `zhuwei.zone-effect/v1`：区域种类（重度遮蔽、沉默）、场景、球心（施放时冻结的区域原点）、半径（法术的球形半径）。与状态效果、修正效果共用持续时间、到期与专注维持的逻辑；区域按施法者的时钟计时，结束事件也挂在施法者身上。每次施放只建一个区域，不按区域内的目标逐个建。
2. **遮蔽。** 不借用场景里的不透明障碍：障碍还会提供半掩护到全掩护、挡住区域扩散，浓雾都不会。单独判定：两个生物中心之间的线段（含高度）与重度遮蔽球相交时，彼此看不见。接入攻击优劣势（两项同时加，相互抵消）、闪避与借机攻击用的“看见”、反制法术的“看见施法者”、躲藏察觉。
3. **沉默。** 生物占位的八个角都在球内时算完全在内：耳聋（不能听）、免疫雷鸣伤害。施法者中心在球内时，不能施放带言语成分的法术；施法、预备法术和反应法术（护盾术、反制法术）都检查。
4. **成分。** 法术目录为每个法术写上 SRD 5.1 的言语、姿势、材料成分，编译进法术的 `activation.components`。

## 影响

- 云雾术、沉默术可以施放并生效。
- 地图还不画这些区域：投影的 `knownZones` 由 `projector.ts` 填，本次没有改。
- 要求“看得见目标”的法术目前并不检查视线（既有情况），浓雾也就不挡它们的目标选择。
- 姿势与材料成分只记录，不检查（被束缚、双手被占、没有法器的情况既有实现未建模）。
- 不改持久化结构的外层；效果记录多一种。
