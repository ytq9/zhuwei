# ADR 0150：法术写明的持续状态由 Rules 施加，随专注结束，回合结束重新豁免

- 状态：已接受
- 日期：2026-10-11
- 依据：用户发现行动列表里有施放必被拒的法术，在「不列出它们」与「补上执行器」之间选择了补上执行器。这是分批中的第一批：状态类法术（人类定身术、隐形术、魅惑人类）。
- 当前规则：[SPEC 0012 §9.2](../specs/0012-part-b-abilities-damage-and-conclusion.md)（非伤害能力在遭遇中可以指向任何生物）、§10.1（法术状态、提前结束条件、回合结束重新豁免）、§10.2（专注与它维持的状态绑定；开始施放新的专注法术时旧专注立即结束）。
- 取代范围：无。

## 原因

- 角色编译把法术目录里的效果只保留成描述记录 `{tag, label, kind}`。Rules 施放时只执行 `grantEffect`/`endEffect`、单独的专注和豁免失败时的推开，其余效果让整个法术被拒，扣费和掷骰之前就拒。法师 3 级准备全部目录法术时，编译出的 26 个法术里有 17 个施放必被拒，行动列表却照常列出它们。
- 状态的执行器（`grantEffect`）早已存在，麻痹、隐形、魅惑的 2014 机械也已实现。缺的是：专注只在「不掷骰也没有状态效果」的法术上才会开始；专注结束时没有东西结束它维持的状态；没有回合结束时的重复豁免；没有「攻击或施法后结束」「被施法者一方伤害后结束」这类提前结束条件。
- 遭遇中，治疗以外的能力只能选敌对目标，对自己或盟友施放的增益法术根本选不到目标。
- 旧专注要到新法术结算时才结束。新法术被反制时，旧专注会留下来，与 SPEC 0012 §10.2 不符；而旧专注现在还维持着状态。

## 决定

1. **编译。** 目录里 `kind: "condition"`、且标签是 2014 状态名的效果，编译成 `grantEffect`，带上目录的 tag 和 label 供旁白使用。持续时间取自法术：限时的给微秒数，写明「到施法者或目标下回合开始/结束」的给回合边界，特殊持续给「直到结束」。专注法术的状态标记为靠专注维持；法术写明每回合结束重新豁免的，状态带上重复豁免；目录新增结构化字段 `endsWhen`，隐形术写「目标攻击或施法」，魅惑人类写「施法者一方的伤害性行为」。法术定义 id 的后缀从 `compiled-v2` 升为 `compiled-v3`，已开房间在下次编译时登记新定义，不与旧定义冲突。
2. **效果记录。** 状态效果记录新增可选的 `lifecycle`：是否靠专注维持、重复豁免（施放时冻结的属性与 DC）、提前结束条件。旧记录没有这个字段，照常回放。
3. **专注。** 开始施放专注法术时，在施法事件之后结束旧专注（`replacedByNewConcentration`），它维持的状态随之结束。新法术至少在一个目标身上留下状态时才开始专注（专注记录带 `linkedEffects`）。专注结束时，它维持的状态全部结束（`concentrationEnded`）；它维持的状态全部结束后，专注也结束（`spellEnded`）。
4. **重复豁免。** 遭遇中，回合结束事件提交之后、下一个回合开始之前，Rules 为该生物身上每个要求重复豁免的状态请求一次豁免骰，记为新事件 `EffectSaveRepeated`；成功的随即 `EffectEnded`（`repeatSaveSucceeded`）。之后照常进入下一个回合，或在轮末先掷死亡豁免。
5. **提前结束。** 能力结算后、施加自己的状态之前：使用者攻击过或这是一个法术时，结束使用者身上「攻击或施法后结束」的状态；被反制的法术也算施过法。这次使用对目标进行了攻击、要求了豁免或造成了伤害时，结束目标身上由使用者一方施加的「伤害后结束」的状态。同伴是同一遭遇中与施法者互不敌对的参战者；遭遇之外，玩家角色互为同伴。魅惑人类在对方正与施法者一方交战时豁免有优势。
6. **目标。** 不进行攻击（含代替攻击的对抗）、不要求豁免、不造成伤害的能力，在遭遇中可以指向射程内的任何生物。伤害性能力仍只能指向敌对的参战者，这一既有限制本次不变。

## 影响

- 人类定身术、隐形术、魅惑人类可以施放；其余 14 个法术（数值修正、区域、召唤、诱捕打击、命令术）仍在施放时被拒，留给后续批次。
- 新事件类型 `EffectSaveRepeated` 只记录掷骰，不改变状态；旁白依据为一条豁免结果。
- 遭遇之外没有回合，重复豁免不发生，状态按持续时间或专注结束。
- 不改持久化结构的外层；效果记录多一个可选字段，专注记录多一个可选标记。
