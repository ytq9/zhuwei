## 能力合同

玩家和 NPC 的新战斗选择从现役入口进入同一 Rules，保留目标、资源、回合授予、私人决定和事件恢复边界；撤离只在实际合法移动之后改变遭遇成员及位置。长局分段摘要只依据该角色持有的精确版本知识，作为不可引用的目录提示，不替代原记录或世界事实。依据为 SPEC 0001 §§8、9、14、16，SPEC 0012 §§3.4、6.3、7、9–13，SPEC 0016 §4.3–4.5，以及 ADR 0111 已批准的模型分段摘要方向。

## 代表性矩阵

| 范围 | 正常与变化样例 | 高风险边界 |
| --- | --- | --- |
| NPC 战斗定义 | 多重攻击的不同攻击组合、免疫／抗性／易伤、命中或失败豁免后的状态 | Multiattack 不等同 Extra Attack；不能换成擒抱或从一次动作获得无限攻击；未命中不加状态 |
| 玩家武器与施法 | 两把轻型武器的附赠攻击、结构化投掷及实物落地、临时武器、升环伤害或治疗 | 未先攻击不能副手攻击；投掷不复制武器；法术位和伤害等级一致 |
| NPC 回合 | 急救同伴；对玩家擒抱／推撞时等待本人选择运动或体操 | NPC 不代选玩家；等待与恢复不重复消耗动作或重掷 |
| 脱离与结束 | NPC 逃离、单个玩家离开多人遭遇、地图出口、全部玩家倒下或死亡 | 路径、速度、封闭出口和借机攻击生效；未成功到达不能宣布逃离；不自动判死亡或俘虏 |
| 分段摘要 | 多角色、不同场景和天数的历史段；目录读取及原文回读 | 私密持有者隔离、原记录变化后旧摘要失效、恢复不重采样、归档保留调用和来源证据 |

## 实施与验证约束

先复用已有能力定义、伤害／效果、行动授予、移动和 continuation，再接入现役玩家及 NPC 入口。普通攻击、额外攻击与怪物多重攻击保留不同来源与限制。开战不会为了表达新能力改写已固化数值。

摘要沿 ADR 0111/0115 的知识目录扩展：稳定段来自完整本人知识的场景／天数归组与记录版本，不使用随本次意图变化的未读组成员充当永久段身份。调用使用现有 journal、预算和精确请求恢复；每次处理最多准备一个有界段，保留原来的目录和原文回读机制。

名称显示是交接中明确未定事项，已向用户询问，答复前不改已裁定的观察者名称规则。其他由现有 SPEC 决定的行为直接实施。
