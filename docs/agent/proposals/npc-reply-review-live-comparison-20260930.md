## 要回答的问题

不带思考的审核会不会漏掉越权知识和成败分支的往事矛盾？将理由放到结论之前是否足够，还是需要像 [ADR 0069](../../adr/0069-the-deepseek-narration-review-reasons-before-it-reports.md)中的旁白审核那样开启思考？

代码确定性验证负责引用、绑定和权限。不同 id 的自然语言命题是否矛盾由语义审核判断；不增加关键词真假规则，不要求成功和失败披露完全相同的内容。

真实材料中的秘密和私有动机只保存到本地私有证据，不写入公开报告。第一、三例简化为单一普通交谈，沿现役函数重新生成 hearing、reply、review ticket 和 hash，不沿用旧工单。它们是有控制变量的审核样本，不是原行动全链路重跑。

每例三个配置，各一次：

1. A：旧的结论在前、理由在后，不开思考。
2. B：理由在前、结论在后，不开思考，与当前审核 schema 的顺序一致。
3. C：与 B 同序，增加 `thinking: enabled`、`reasoning_effort: low`；按 DeepSeek 接口要求使用 `tool_choice: auto`。

三个配置使用相同材料、提示文字、schema 字段和缓存布局，实验输出上限统一为 16,384 token，覆盖思考与报告。生产审核仍为 4,000；这次实验不自动改变房间预算。保存实际请求字节的 SHA-256，避免 canonical hash 忽略字段顺序。

## 模型、预算和停止条件

- 模型请求名称保持 `deepseek-v4-flash`，使用生产的 DeepSeek strict beta binding，不换供应商或普通端点。
- [官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)在 2026-09-30 声明该旧名称已由 DeepSeek-V4.1-Flash 提供服务，按 Flash 计费。报告同时记录请求名称与响应模型；本批结论不反推旧版表现。
- 最多 12 次调用；估算输入合计 224,166 token，上限 300,000；输出合计最多 196,608 token。
- 每次最多 90 秒，全批最多 15 分钟。
- 预算人民币 3 元。按高于当前 Flash 标价的旧高峰价保守计算（输入未命中 ¥3/百万、命中 ¥0.10/百万、输出 ¥9/百万），全部未命中且输出用满时约 ¥2.442；这是估算预算，不是账单保证。每次派发前检查剩余额度，响应后记真实 usage。
- 顺序运行、不重采样、不自动替补；首个接口失败、格式失败、截断、未知结果、usage 缺失或预算不足即停，保留全部已发生尝试。
- 语义误判是本对照的观测对象，记错后继续剩余固定对照，不修改用例挑成功。
- 不生成 NPC 新回复、不运行旁白、不写入房间、不部署。

## 采用条件与局限

若 C 修复了 B 的漏判，且四例无新增误拦、格式失败，才支持讨论在 DeepSeek 的 NPC 审核中开启思考，并同步输出预留、版本和直接消费者。若 B、C 都通过，本批不能证明额外思考成本必要。批次授权本身不自动授权长期增加调用预算。

四个样例只能提供定向证据，不能证明任意语义矛盾都能发现；也不能代替完整 NPC 作答、审核、提交、发布及后续回读的真实链路验收。缓存使用串行预热，配置间费用/耗时不是随机试验；可以记录命中数，不能将差异全部归因于思考开关。
