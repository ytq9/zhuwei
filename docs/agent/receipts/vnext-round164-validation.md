## 看到的

- **躲藏、开口结束躲藏、推开 5 尺都在状态里发生了。** 164-1 与 164-3 的旁白与状态一致。
- **v81 的"只写一次"这三批里都生效了。** 三次用到脚本的填写都只写了一个步骤（164-4 第一稿把两个脚本都放在 steps 里是另一类错误）。
- **v82 之后，KP 对"顶开"用了推撞脚本和对抗。** 只有一个样本。
- **复杂一点的组合（对抗 + 扛走 + 放下）KP 没能在三轮内写对。** 每轮只修一个问题，诊断不汇总；`duration` 写成 none 可能受 walkTo 那句"遭遇外 duration=none"影响，属推断。
