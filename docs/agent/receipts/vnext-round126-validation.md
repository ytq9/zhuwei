# round126：只在结果确实不定时检定，普通问话不掷骰

2026-09-26。三句行动加一句对照，每句一个新房间，`tools/run-story-room-probe.mjs --live --max-calls 6`，真实 HTTP 路径，`deepseek-v4-flash`。修复源码 `450da31`（指引 v49），对照源码 `2d7e39a`（指引 v48）。都在 `cloudflare` 的干净克隆上运行，不含主工作区里另一个会话未提交的改动。未部署、未 push、未做远端 migration、未改 Secrets。

## 为什么跑这一批

用户问检定是不是太频繁。线上房间 9DCMQN 的归档（68 个事件）里 5 次行动全部掷骰：

| 行动 | 裁决 |
| --- | --- |
| 从遗体齿间取出黑橡叶，就着烛光细看 | 调查，智力 DC 11；失败写的是「看不清，可以换个光源再看」 |
| 「我拿去问 lian，她关于这片叶子知道些什么」 | 魅力 DC 13 |
| 「什么信？」 | 魅力 DC 13 |
| 「第三份什么东西」 | 说服，魅力 DC 12 |
| 「转头去问奈斯，他知道那片黑橡叶吗」 | 说服，魅力 DC 12，失败 |

后 4 次都是向 NPC 问话。SPEC 0001 §5 要求成败都有意义且结果确实不定才检定，§6 写明没有有意义失败的行动不掷骰，§14 写明 NPC 依据自己的目标和知识行动。指引里有两句把几乎所有问话都推向检定：

- `69c3471`（v46）：「请交谈对象配合、答应、透露或相信，而对方未必同意时……要检定；对方必然同意或必然拒绝时才不掷骰」。问话都可以算作请对方透露，而模型很少判断对方「必然」同意。
- `0f8bd8f`（v36）：「失败会改变关系或处境的尝试都算有意义风险」。通用裁决里没有「结果确实不定」这个条件，问话失败可能让对方起戒心，于是也算有意义风险。

`450da31` 改为：结果确实不定且失败有意义才检定，否则直接成功；问话和寻常交谈不掷骰，对方按本人目标、知识和态度回应；要对方做不愿做的事、说出想瞒的事或相信可疑的话（说服、欺瞒、威吓等），结果确实不定时才检定。瞒着旁人的举动或话仍算有意义，用户在 [round109](./vnext-round109-validation.md) 要求的「偷偷做的动作要过检定」不变。

## 没有覆盖的

- 每个条件各一个样本。模型输出有随机性，这一批只说明改动后的指引能让普通问话走直接成功，不说明每次都会。
- 9DCMQN 本身没有重跑；修复没有部署，线上仍是 v48。
- 取叶子细看那一类观察检定：新的通用条件（结果确实不定）同样适用，但这一批没有跑观察用例。那次失败只写「看不清，可以再看」，没有带来变化，这一点本次没有另改。
- 每次问话仍按「5 分钟」档位推进虚构时间，本次没有改。
- 对照句的失败分支让莉安「听出」玩家心里的盘算，这是另一个问题（听者不应知道心理活动），v49 下这句不再检定，所以没有出现；本次没有另查。
