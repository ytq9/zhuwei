## 看到的

**修订进行了。** 首稿把隐蔽检定挂在了对莉安的问话上，这正是 [ADR 0066](../../adr/0066-the-step-under-a-concealed-check-is-the-hidden-act-not-the-talk-with-its-observer.md) 规定要拒绝的写法。lowering 拒绝，错误码是 `PROPOSAL_FORM_INVALID`，诊断标明允许修订。修复之前这条拒绝会直接结束行动；这次它进入了修订。

- 第一轮的补丁里有重复的 JSON 成员，被拒。
- 第二轮的补丁里有一个操作带了多余的成员，被拒。
- 第三轮模型整份重填：隐蔽检定（巧手）挂在 worldInteraction 上，取叶是绑定 onSuccess 的库存操作，问话是绑定 always 的 social。通过。
- 三轮修订全部用完，没有余量。

**检定和结果。** Rules 取莉安的被动察觉 11，按“分心”调整后 DC 6；骰 6+2=8 成功。莉安没有察觉，叶子进了行动者的库存（`InventoryOperationApplied`）。奈斯和瓦罗按各自的档位察觉了，各开了一次当场反应。瓦罗的反应由他本人的调用决定并发布了旁白；奈斯的反应因为第 14 次调用被探针拒绝而作废（`lapsed`，`ACTOR_PLAN_DECISION_CALL_BUDGET_EXHAUSTED`）。

**莉安听到和看到的。** 两份作答请求里都没有玩家原话里的“装作”“趁莉安不注意”，没有裁决写的任何一段文字（两份裁决共 16 段），也没有神龛、枯骨会等主持人材料里的词。行动提交后，莉安的记录里有那句问话，没有被瞒的意图。

**第一次作答作废了。** 首稿里问话挂在检定下，莉安写了成功、失败两份回答。修订后问话不再挂检定，她听到的内容变了，按规则重新作答一次。裁决的结构错误要到作答之后才由 lowering 发现，所以多了一次作答调用。

## 结论

- `7dd0b90` 在真实调用里起了作用：错误码不是 `PROPOSAL_REFERENCE_INVALID` 的 lowering 拒绝进入了修订，行动在第三轮修订后提交。
- 隐蔽动作加问话的流程走到了掷骰、库存变化、旁白和一名旁观者的当场反应。被瞒的意图没有进入莉安听到的内容和她的记录。
- 这次运行没有完成：探针的重复提交核对没有执行，奈斯的反应没有由模型决定。

## 观察到、没有处理的

1. 莉安对“父亲是否常来”的回答没有依据。她的记录里没有这件事；作废的那份回答说常来，发布的这份说不常来，两份相反。作答的提示要求记录里没有的事说不知道，这一问没有照做。旁白把它标成了她的说法。
2. 旁白第一段有库存记账式的句子：“这片‘齿间的黑橡叶’现在归你所有，一共一件。”
3. 修订的前两轮都败在补丁的 JSON 格式上，不是败在内容上。
4. 裁决的结构错误在 NPC 作答之后才被发现，每次多一次作答调用（约 7,800 输入 token）。
5. `daily-hidden-act` 在有旁观者察觉时需要 14 次以上调用。探针每次运行的上限是 16 次。
