## 结论

- v61 之后三稿填写里的每个档位都带了依据；玩家说「奈斯盯着我」的那次，模型给奈斯「看着」引用的是开场描写和奈斯的记录，不是玩家的话；玩家没提奈斯的那次，奈斯按默认「未特别注意」。
- 模型仍会把默认档位的人也列出来（143 三人都列了）。规则允许：列出的档位等于默认，依据也在。
- 探针的 `concealment` 记录可用于跨批次比较档位。

## 没有覆盖的

- 142 第 1 次的失败是 worldInteraction 步骤本身不合法和社交上下文校验失败，本次没有排查。
