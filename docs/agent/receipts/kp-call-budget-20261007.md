## 实现及边界

1. 定义与模组材料提前，变化的意图/hash 后移，按选择加载的正文仍排在共享记录之后。完整因果、权限与状态材料保留；当前数量不会被缓存旧值替代。
2. 既有普通容器用显式取放声明，服务器展开现有开、取放、关原语；当前场景绑定由冻结行动者记录组装。目标、方法、风险、数量、时间及是否合盖由 KP 决定。不是根据玩家原话自动猜测操作。
3. 冻结身份使用稳定短引用，原回复、readSet 和实际实例身份保留。简单执行修订只提供结构化替换，修订说明只发送一次，后续附加原回复与新工单。共享 schema 的引用槽与枚举词汇分开处理；Room 从原冻结映射复核。
4. 记录实际提交、修订、缓存、费用和耗时。取出、放入分别限制合法冻结来源，放回不能选择盒内剩余堆或同桌物品；不合规回复仍由服务器拒绝，诊断指向实际字段并列出合法候选。

技术决定见 [ADR 0131](../../adr/0131-frozen-wire-references-and-declared-container-transfer.md)。Parser v86、模型上下文 vnext-16、指导 v104；Rules/event schema/存储结构、90k 运行输入上限和调用额度不变。独立 NPC 决策未切换短引用或容器脚本；同束新对象及其他复杂组合仍使用既有原语。
