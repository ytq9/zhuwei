## 直接引语：做到了

旁白正文分三段：第一段复述玩家的问题；第二段是 `莉安说：“……”`，整句原话放在引号里，没有拆成“她说……她还说……”。

**新问题**：第三段又把台词内容总结了一遍（“这些是莉安的说法：叶子的事她是听来的……第三份遗嘱是她父亲生前告诉她的……”）。这和引语重复，读起来又回到了清单式转述。推测是 `FACT_BOUNDARY` 要求“保留来源与不确定性”，模型因此另写一段来源说明。这只是推断，还没有改。
