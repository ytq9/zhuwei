# round176：NPC 按本人视角投降、接受投降，被饶过后再动手

2026-10-05（北京时间约 23:12–23:41）。用户裁定："投降 NPC 按照自己的视角决定，可以部分投降，也可以投降后反叛，这要看 NPC 的决定"。本轮用真实模型验证：
- 战斗中的立场（[ADR 0117](../../adr/0117-an-npc-yields-or-turns-from-its-own-view.md)）；
- 战后记忆与再次开战（[ADR 0118](../../adr/0118-npcs-remember-fights-and-may-start-new-ones.md)）。

三个用例都开局在奈斯身边交战，玩家先行动：
- `combat-demand-surrender`：奈斯 4/38 HP，玩家开口劝降；
- `combat-surrender`：玩家自己丢剑投降；
- `combat-spared-rebel`：劝降，饶过之后玩家转身取走黑橡叶。

## 看到的与修复

**176-1：玩家承诺由服务器按原话填写。**
- Rules 只接受内容与玩家原话完全一致的玩家承诺。KP 只写了后半句，而这个错误到 Rules 执行时才暴露。
- 修复为 `f3e99c90`：玩家一方承诺的内容和改约的引语都由服务器按 `actorSpeech` 填写，KP 的表单不再要这两栏，做法与 NPC 改约引语相同。
- 交谈请求因此缩小 28 token。

**176-2：检定只说话起没起作用，立场由 NPC 自己定。**
- KP 把威吓成功写成"奈斯被逼住，认为继续握锤没有好处"。奈斯在这个分支里选择继续打，审核两次退回，行动失败。
- 修复为 `7a6e61e3`：
  - 交谈指引写明：对战斗中的对手说话时，成败只写这番话对它起没起作用，不写它投降或继续打；
  - 审核（v10）把战斗立场当作 NPC 本人的决定。
- 交谈请求每次多 59 token，按 ADR 0057 告知后接受。

**176-4：劝降成功。**
- 威吓成功后奈斯自己选择投降，并附带条件："饶他一命，就摊开第二份遗嘱给你们看"。
- Rules 问"对手投降了。是否接受并结束这场战斗？"，接受后战斗结束，原因是 `npcSurrendered`。战后奈斯记得这场战斗。
- 旁白一次通过："他慢慢把钉头锤放到地上……'请不要杀我，我还想活着离开这里……'他不再与你交手，这场打斗到这儿停了。"

**176-5：玩家投降，奈斯在自己的回合接受。**
- KP 用 `endCombat` 的 `actorSurrenders` 只记了玩家一方停手。
- 轮到奈斯时，他说"若是你已把剑放下，那便不必再打了……"并停手（接受投降）。Rules 提议结束，接受后战斗结束，原因是 `playersSurrendered`。
- 有一段旁白给奈斯加了"没有立刻接话、目光落到剑上"，审核删掉了。

**176-6：同一回合同一句话说了三遍。**
- 奈斯的计划是"说话 → 预备：玩家移动就走到楼梯脚 → 结束回合"。他本来就站在楼梯脚旁边，预备算不出路径，执行时报 `ready:unavailable` 停下，而说话已经执行了。
- 重新要计划时，他不知道 `interruption` 的含义，交了同样的计划，于是又说了一遍。三份计划、三段旁白，用了 6 次额外调用。
- 修复为 `a5c1e2c3`：
  - 预备的移动目的地就是现在位置时，按"原地不动"处理，计划继续；
  - NPC 回合说明补了一句：`stoppedAtStep` 之前的步骤已经做了，只写本回合剩下的部分。

**176-7：修复后奈斯的回合只要了一次计划**（说话、闪避、结束回合）。
- 他这次没有投降。他开局满血，这是他自己的选择。
- 第 5 步取叶子时，KP 选表只加载了物品操作，却写成隐蔽检定，缺少检定需要的那一步，修订后仍不对。这与投降和反叛无关。

## 结束战斗的旁白

round175 结束时的旁白像系统提示。`10dee7ae` 把"提议结束及原因"改为结算材料，KP 写的那一刻的描述单独成一条：
- 接受时讲战斗结束；
- 拒绝时只讲轮到谁行动，走服务器固定句。

176-4、176-5 的结束旁白分别是"这场打斗到这儿停了""这场冲突到此结束"。

## 没有覆盖的

- **被饶过的 NPC 再次开战**没有真实样本。这一路径要先等 NPC 自己投降、玩家饶过，两个决定都不可控。需要一个开局就处在"投降过、被饶过、记得这场战斗"状态的固定场景。
- **部分投降**（两个对手一个投降）没有真实样本。
- **回合中途停下后的重新要计划**：只补了说明，没有在 Rules 里按整个回合限制说话次数。
- **176-1 的旁白里有记账句**："这条承诺还没有兑现——他既没放下锤子，也没投降"，来自玩家承诺那条材料。
- **176-7 的隐蔽动作选表错误**，没有处理。
