# round109–111：NPC 只听到说出口的话；隐蔽动作要过检定

2026-09-23。三批都用 `tools/run-story-room-probe.mjs --live --max-calls 10`，真实 HTTP 路径，`deepseek-v4-flash`，每批一句行动。均未部署、未 push、未做远端 migration、未改 Secrets。

## 背景

`b94c2db` 让交谈步骤带 `actorSpeech`：NPC 听到的是它，而不是玩家输入的整段原文；玩家加引号的原话必须逐字保留。用户补充：偷偷做的动作要过检定，检定失败时 NPC 会发现。

## round109：公开提问夹着心理活动（源码 `7f475cf`）

用例 `daily-spoken-intent`：“我问莉安她父亲生前是做什么的，心里盘算着先摸清她的底细。”

5 次调用，104,758 输入 / 837 输出 token，通过。`actorSpeech` 为“莉安，你父亲生前是做什么的？”；“摸清她的底细”只出现在 KP 私有的 `goal` 里。莉安的记忆里只有这句问话。

旁白末尾多了一句“这些是她说的，不是已经被证实的旧事。”，是旁白规则里“来源主张不等于真相”促成的免责式补句。未处理。

## round110：隐蔽动作加引号问话（源码 `7f475cf`）

用例 `daily-hidden-act`：“我装作替赫斯整理衣领，趁莉安不注意把他嘴里那片黑橡叶顺进袖子里，同时问她：“你父亲生前常来守灵厅吗？””

5 次调用，130,657 输入 / 2,039 输出 token，记忆断言通过：莉安只记下“「你父亲生前常来守灵厅吗？」”，没有“装作”“趁莉安不注意”。

**但 KP 没有设检定**，直接成功。它在风险说明里写了被察觉的后果（莉安警觉、再问酒窖更难），又判断这“属于普通社交摩擦，不构成不可逆危险”。SPEC 0009 §2 把关系或局势改变算作有意义的失败，所以这是裁决错误。`0f8bd8f` 在共享指导里写明：瞒着在场者的举动或话、失败会改变关系或处境的尝试，都算有意义风险。

## round111：同一用例（源码 `0f8bd8f`）

8 次调用，181,891 输入 / 2,377 输出 token，失败。

- KP 这次设了检定：敏捷（巧手）DC 14。掷骰失败。
- 失败分支里只有莉安的台词（“你手在干什么？那是他的脸。有话问我就问，别碰他。”）。没有莉安看到了什么的见证记录，也没有玩家自己感知到“没得手”的记录。
- 旁白写了“藏叶没成功，黑橡叶还留在原处”，审核两次都判为冻结材料之外的事实，行动被整体取消（`action: notCommitted`）。

**原因**：一次检定覆盖多个步骤时，规则只允许一个步骤同时填写成功和失败两个分支。这里是交谈步骤，所以莉安的两种反应有地方写，失败时“没拿到叶子”“莉安看见你的手”却没有地方写。旁白只能靠推断，审核据实拒绝。

## 结论与未覆盖

- 说出口的话与输入分开：两批真实数据都成立。
- 隐蔽动作要检定：改指导后 KP 会设检定，只有一个样本。
- 检定失败时，隐蔽动作的失败结果和见证无处记录，导致行动作废：未解决，需要裁定改法。
