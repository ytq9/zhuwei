### 169-1：补选了常用动作名

KP 选了 worldInteraction，填写时又调用补选工具，要求加 `goTo`。按当时的 SPEC 0016 §7.2，这是未知标识，整个行动以"格式检查未通过"失败，KP 没有修订机会。

修复分两处：

- `21423232`：指引里"只能写 goTo"改为"只能写 commonAction goTo"。
- `d1a307f7`（[ADR 0107](../../adr/0107-a-common-action-named-in-a-selection-is-world-interaction.md)）：选择或补选里出现常用动作名时，按选了 worldInteraction 读取。补选因此没有新增时，按已有规则重新填写一次。条款修改经用户确认。

### 169-2 至 169-4：终点字段

三次都是第一稿就写对：去后院用 goTo，爬沟和翻墙用 `climb/across`，判直接成功。两步的 `successEndsAt` 都写成 `"yard"`，与步骤推算的终点一致，没有触发终点诊断。旁白写的位置与地图一致。

169-4 的一轮补丁，是 KP 把只供参考的 `terrain-checks` 条目写进了依据（round167 也出现过），改掉后通过。

## 看到的

- 终点核对加上之后，三次运行都没有出现"文字说到了、实际没到"。这几次 KP 第一稿的写法都正确，所以终点诊断本身在真实调用里还没有被触发过。
- `terrain-checks` 被当作依据引用，仍会偶尔多花一轮补丁。
