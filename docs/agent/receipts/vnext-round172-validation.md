## 看到的

- **固定句子替代了模型旁白。**
  - 结束回合、轮到奈斯的那段回复，发布的是固定句子，没有模型调用。
  - 172-1 只剩奈斯回合计划，以及闪避那段旁白的写与审。
- **别名问题已修。** 固定句子起初写成"现在轮到奈斯 / 奈斯卡尔行动。"，因为模组给奈斯的名字带别名。`71006c66` 改为只取"/"前的名字，没有重跑真实调用。
- **其他旁白照旧由模型写、经审核。**
  - 172-2 的躲藏旁白是"你藏起身形，尽量不让人发现。"。
  - 奈斯回合的旁白写了"现在轮到原团旅人行动。"：观察者就是原团旅人，但这一轮的行动者是奈斯，写作说明只允许把"行动者"称作"你"，模型就用了名字。这是原有写法的现象，与本次改动无关。
