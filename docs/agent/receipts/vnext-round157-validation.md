## 这批验证什么

[ADR 0081](../../adr/0081-ask-once-after-a-failed-conversation.md) 与 [ADR 0083](../../adr/0083-record-check-and-refusal-precedents.md) 中回答之后的那一段：KP 提问后，玩家回答一个只用自己身体的新做法，同一行动接着裁决并提交。

用例改为（`763fe55`）：第一步徒手把整座石砌炉台拔起来、举过头顶；之后两次再争取，只在没有问题等待时发出；最后一步只在有问题等待时，回答"这次我不硬抬了。我蹲低身子，用肩膀抵住炉台一侧，双腿发力，一点点往外推。"

## 看到的

**第一步判成了直接成功。** KP 没有给检定，也没有判做不到，而是用 `directSuccess` 写结果："他抓住炉台边沿发力，石砌炉台纹丝不动"，耗时 5 分钟。按用户的裁定（DC 和成败按 KP 的最终意图），这是 KP 的裁决。ADR 0083 只把交谈以外的检定和直接准入的"做不到"记为先例，所以这一步没有先例。

**第二步的上下文里没有上一次做了什么。** 第二步的选择请求里，与第一步有关的只有两条感官事实（手抠住炉台边沿、石块不动；炉台砌进地面、连着烟囱）。上一次的意图（把炉台拔起来举过头顶）不在上下文里：没有先例，旁白和意图原文也不在。ADR 0083 决定 3 加入"行动者在本场景最近一次的裁决"，正是为了让"再试一次"有指代；直接成功不记录，这条就是空的。先例条目是"本场景没有先例"，所以也没有提问工具。

**KP 猜成了攻击。** 选择请求了 `abilityOperation`。填写时补选没有新增，按 ADR 0065 重发表单。重发后 KP 填了即兴攻击，目标是莉安。角色的即兴攻击定义写的目标是"生物或环境物件"，但能力表单的目标只能选角色和 NPC，炉台不在可选项里。Rules 以 `Ability target is unavailable.` 拒绝（莉安不在触及范围内）。修订把目标改成炉台，炉台不在可选项里，再次被拒，行动未提交。没有提交任何攻击。

## 结论

- 回答之后的裁决仍未在真实调用里验证：这一次第一步是直接成功，没有走到提问。
- 新发现一个缺口：上一次裁决是直接成功时，"再试一次"在 KP 的上下文里没有指代。这次 KP 因此把再试一次当成了即兴攻击，并对准了在场的 NPC；只是因为目标不可用才没有提交。
- 另见：即兴攻击的定义允许以环境物件为目标，能力表单却只能选角色和 NPC。

## 没有覆盖的

- 回答之后的裁决（有理由的回答、不补充的回答）。
- 交谈失败后的再争取，以及 ADR 0084 的审核退回裁决（本批没有交谈）。
- 说出理由或愿意再付代价时不问。
