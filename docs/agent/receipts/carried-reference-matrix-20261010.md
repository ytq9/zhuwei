# 随身物指代矩阵真实调用：13 次 8 次提交

日期：2026-10-10。分支 `cloudflare`，探针用例 `3422b104`。批次中修了两处产品缺陷（`935fa64b`、`861427df`），批次后又修了一处（`eeeb76f8`）。按用户批准的方案：6 个场景各 2 次，句子都是事先写好、开发时没用过的；先做零调用预检；每次最多 10 次调用、30 万输入、4 万输出 token，合计最多 100 次。工具或夹具出错立即停；模型出错记为数据，不重采。

## 场景与句子

前史由 Rules 直接写入，不算模型样本：行动者把三块布条放进随身木盒并合上，两块放进敞口木桶；每个场景再走一段"怎么到手"的前史。每对同类物品都同名，只有到手方式能区分。

| 场景 | 前史 | 句子 |
| --- | --- | --- |
| 盒子 | 开盒取出一块后合上 | 我把刚从盒里摸出来的那块布塞回去，然后把盒子盖好。 |
| 木桶 | 从木桶取一块 | 刚才从木桶里拿的那条布，我还是放回木桶里吧。 |
| 两个来源 | 盒子、木桶各取一块，合成一叠 | 我手上有两块布，把从木桶里拿出来的那块放回木桶，另一块先留着。 |
| 捡起 | 捡起地上的钥匙，手上已有一把同名钥匙 | 我把刚从地上捡起来的那把钥匙收进布袋里。 |
| 被交给 | 同桌把麻绳交给行动者，行动者已有同名麻绳 | 同桌见证人刚才递给我的那捆麻绳，我把它收进布袋。 |
| 隔几次行动 | 从盒子取出一块，之后两次无关的取放 | 我把之前从木盒里拿出来的那块布放回木盒，再把盒盖合上。 |

六个场景的零调用预检均通过，预检状态里的到手记录与设计一致。

13 次中 8 次提交，旁白都通过审查。失败的 5 次：产品缺陷 2 次，模型选错 2 次，模型输出违反重复成员策略 1 次。

## 发现的产品缺陷

1. **生成的开盖、合盖步骤照抄了声明的依据**，其中包括被放回的那块。那块并入盒内的一叠后不再存在，合盖步骤被判为读集过期。`935fa64b` 改为生成步骤不引用被移动的物品。
2. **KP 自己写的世界交互步骤引用已并入一叠的物品**，同样被拒，且拒绝没有字段位置，修订无从下手。`861427df` 让同一行动里前面步骤移除的记录可以出现在后面步骤的读集、依据、其他对象和证据依据里；直接对象、工具和观察对象仍须存在。
3. **数量超过一叠被报在 `entryRef`**。这是第 2 项（`e6b860ef`）把 `invalidItemPlacement` 一律映射到 `entryRef` 造成的。批次后改为报在 `quantity`，写明上限，不给其他物品候选。

三处都在物品引用审计里加了对照或错误条目，不修时能复现批次里的拒绝。
