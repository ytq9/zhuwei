- **168-1**：奈斯的回合由一次调用决定：走到账台旁、闪避、结束回合。之前那段"轮到你行动"的旁白，第一稿多写了"奈斯仍站在守灵夜那边，没有开口"，审核以"冻结资料中没有依据"退回；重写为"战斗轮到你行动。"后通过。
- **168-2**：奈斯这次用了借机攻击（1 次调用），没有命中。旁白为"奈斯趁你移动时挥出一击，没能打中你。你大约移动了十五尺。"，一次通过。
- **168-3**：躲藏的潜行总值是 7。奈斯回合开始时察觉到了行动者，随后移动并结束回合。三段旁白都一次通过。

## 看到的

- 先提交、后写旁白的路径在真实调用下可用，审核能拦下编出来的事实。
- 旁白偏向记账，原因都在写作者收到的说明材料里：
  - 同一回合的多段移动逐段报出（"先后移动了约3尺、4尺、8尺和14尺"）；
  - 闪避照念规则效果（"直到它下个回合开始，它看得见的攻击者对它出手有劣势……"）；
  - 躲藏只有"动作已经做出"，没有说躲到了哪里。

  要改就改说明材料，不改提示词。本轮没有改。

## 没有覆盖的

- 旁白失败后再重试的真实样本（三次都没有失败）。
- 玩家自己的武器攻击：这三个用例都没有出手。
- 记账句的材料修正。
