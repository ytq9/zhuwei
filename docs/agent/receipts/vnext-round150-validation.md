## 这批验证什么

[ADR 0071](../../adr/0071-the-second-review-may-correct-once-more-before-a-final-review.md)：复审判 `revise` 时也给出改好的正文，第二次改好的正文接受终审，一条回复最多四次调用。策略 `zhuwei.text-narration/v5`。

样例是 [round149](vnext-round149-validation.md) 的 V3，也就是 9DCMQN 原症状。它的审核和复审已经在 round149 里真实调用过，两次都判 `revise` 并各给出了改好的正文。本次没有重发这两个请求：脚本先证明工作区的现役代码生成的审核、复审请求与 round149 发出的请求哈希相同，再只发送终审这一个新请求。

## 结果

| 阶段 | 来源 | 结论 | 候选正文里被指出的问题 |

| 审核 | round149 | revise | 把瓦罗按着盖印文件的动作写到奈斯名下；“遗嘱”没有注明是奈斯的说法 |
| 复审 | round149 | revise | 奈斯原话的条件是“若您信这些风言”，正文写成“不肯看” |

终审输入 7,243（缓存命中 768）/ 输出 9,040 token，其中思考 8,968；耗时 44.7 秒；按高峰标价重算为 ¥0.101。

现役的 `reviewedNarrationBody` 由这四个阶段的响应得到发布正文，即第二次改好的正文：

> 你问的是“什么纸”——按刚才的情形，指的是书记官瓦罗按在账台上的那份盖印文件，也就是奈斯口中称作“这份遗嘱”“这卷纸”的东西；莉安提过的那封信和第三份东西是另一回事。奈斯方才说，今晚镇上等的是这卷纸上的结果：你肯看，他就展开给你看；若你信那些风言，那就没什么可谈的了。

## 结论

- 按 ADR 0070 会失败的 V3，按 ADR 0071 能发布。动作主体和奈斯原话的条件都已改正。
- 发布正文仍然断言瓦罗按着的盖印文件就是奈斯所说的“这卷纸”。该观察者的冻结材料里没有记录说明两者是同一份文件。终审的思维链考虑过这一点，认为属于有依据的归纳，没有当成问题。三次审核都没有改掉它。
- 终审用了 8,968 个思考 token 和 44.7 秒，是五批里最慢的一次审核。这条回复四个阶段合计约 64 秒。
