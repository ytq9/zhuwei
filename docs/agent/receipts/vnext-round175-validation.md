# round175：地图上的一击、倒地与急救、结束战斗

2026-10-05（北京时间约 18:00–21:46）。用户选了"攻击到死亡的链路"和"结束战斗的入口"。这一轮用真实模型验证：
- 地图上的一击（[ADR 0113](../../adr/0113-the-strike-chain-on-the-combat-map.md)）；
- 敌人都倒下后由 Rules 提议结束战斗（[ADR 0112](../../adr/0112-vnext-kp-ends-combat.md)）。

两个用例都开局就在奈斯身边与他交战，玩家先行动，用预设骰固定命中与伤害：
- `combat-strike`：奈斯 9 HP，0 HP 即死；
- `combat-strike-down`：奈斯 2/38 HP，0 HP 时做死亡豁免。

## 各次看到的

**175-2：出手、命中、伤害、奈斯还击。**
- 长剑命中，总值 20，造成 7 点挥砍伤害，奈斯剩 2 HP。
- 奈斯在自己的回合用钉头锤还击，打出重击，造成 6 点钝击伤害。旁白为"奈斯用钉头锤出手攻击，这一下正中你，是重击，你因此受到6点钝击伤害"。
- 第一段旁白，写手把伤害方向写反了（"他对你造成了7点挥砍伤害"），还给奈斯编了台词，审核两次退回后改对。
- 原因：写手拿到的"能力 长剑"这条材料把出手者自己当成了目标。武器攻击的结果里不写目标，Claim 找不到就退回出手者。修复为 `e62945ce`：从冻结的掷骰取目标，与命中结果同一来源。

**175-3 → 175-4：击昏选择。**
- 一击把奈斯打到 0 HP，Rules 问攻击者"是否改为非致命击昏"。但表格层的白名单没有这一项，玩家看不到，行动就一直停着。
- 同一处还丢了所有反应选择的按钮，界面渲染时会出错。修复为 `2757d913`。
- 修复后 175-4 走完：命中 → 选致命 → 奈斯昏迷、濒死 → 奈斯的回合只做死亡豁免，不调用模型 → 玩家急救，医药 14 对 DC 10，奈斯稳定。
- 175-4 的死亡豁免旁白是"死亡豁免已累计成功一次、失败零次"。用户裁定要改，见 [ADR 0116](../../adr/0116-a-death-save-is-told-as-it-looks.md)（`7019cf3e`）。

**175-5：击昏后接受结束。**
- 11 点伤害把奈斯打倒，选击昏，奈斯昏迷且稳定。
- 结束回合时 Rules 问"与你们为敌的已经没有谁还能战斗。是否结束这场战斗？"，接受后遭遇结束，原因是 `hostilesCannotContinue`。
- 结束时的旁白是"敌对方已经没人还能打了。战斗结束。"，读起来像系统提示，待改。

**175-7：拒绝结束，继续急救。**
- 拒绝后回合照常结束，战斗继续。
- 新的死亡豁免旁白为"奈斯还是没醒过来"。
- 拒绝这一段的旁白里，写手给已经昏迷的奈斯编了一段台词，审核没有拦下。下一段又借奈斯的说话风格写了"先前那副'请人帮忙'的神情自然也无从谈起"。
- 原因：材料里仍附着昏迷者的说话风格。修复为 `587209cd`：昏迷或死亡的人不再附说话风格。修复之后没有再跑真实调用。

## 没有覆盖的

- `587209cd` 和 ADR 0116 修复之后的真实样本。
- 结束战斗时偏系统提示的旁白。
- `combat-surrender`（玩家开口投降）没有跑。用户随后裁定 NPC 按本人视角决定投降，这条路径要改。
- 记录里的 `replyMentionsWeapon` 取的是当时的 KP 消息，取到的是击昏提问而不是旁白，所以是 `false`。它只是备注，不是断言。
