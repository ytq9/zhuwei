## 这几批验证什么

[ADR 0061](../../adr/0061-npcs-move-by-their-own-decision-and-the-table-shows-who-is-present.md) 的实现：NPC 本人的决定（履行承诺的 NPC 工作）提交 `CharacterMoved`，离开后不再算在场，桌边册「在场」页随之变化。用例两句：第一句请 NPC 去别处，第二句玩家做一件与该 NPC 无关的事。验收要求第一句登记该 NPC 的承诺并排出其工作、NPC 仍在大厅；第二句恰有一次该 NPC 的 `CharacterMoved`、NPC 不在大厅、「在场」列表不含它。

### round141 的经过

- 第一句，4 次调用。莉安不肯去客房：父亲停在堂里，汤要看火，走开会被人看见。她改约在后门外的院子单独谈：「我把这锅汤交代给帮工就出来，你先去，我随后到。」结果登记了她的承诺（`PromiseMade`、`NpcWorkProposed`），summary 没写她已离开。「在场」页列出莉安、奈斯、瓦罗，都是在任、存活、清醒。
- 第二句，10 次调用。开始时莉安的工作先到期。选择调用加载了 materializeObject 和 worldInteraction，填写只用了 worldInteraction：`moveNpc` 去已登记的场景 `yard`（后院与酒窖门），路上耗时 `none`，并给玩家、奈斯、瓦罗各一条看见她从后门出去的感官证据。她的去处目录里也有「莉安私谈（楼上客房或炉边角落）」，她按自己的约定选了后院。
- 提交的 `CharacterMoved`：莉安从大厅（主时间线 300 秒）到后院的时间线，出发和到达都是 300 秒，后院时钟从 0 推到 300 秒；她的战术实体随之移到后院。玩家看到的旁白：「守灵夜里，莉安·黑橡在炉边交代了一个帮工看火……推开后门离开了。」承诺复核判为有进展、未完成（人到了院子，还没谈）。随后玩家向瓦罗致意，这一动作的 5 分钟活动在 `CharacterMoved` 之后开始，主时间线到 600 秒。
- 第二句后「在场」页只剩奈斯、瓦罗。两句的重复提交都得到相同结果。

## 结论

- 交谈中答应马上去别处，现在登记为承诺；玩家下一次行动开始时，NPC 本人的工作提交 `CharacterMoved`。离开后状态、战术地图、旁白和「在场」页一致。
- 138–140 的失败有两类：NPC 拒绝或只作有条件的答应，这符合人物，不是缺陷；NPC 答应后 KP 不登记承诺、只在台词和 summary 里写离开，这是用户报告的缺陷，v60 之后一次真实运行通过。

## 没有覆盖的

- 只有一次通过，不能说明稳定性；v60 之后没有再采样。
- 去模组里没有的地方（同一次决定创建动态地点和连接、再经连接走）、经已有连接走、当场反应里的移动、到达有玩家在的场景（「到达」记录）、处在遭遇中或失能的 NPC 被拒，都只有本地测试。
- 138 第一次、139 第二次运行里是有条件的答应（报了名就去、念完这段再去看），没有登记为待生效的承诺。
- 莉安说「你先去，我随后到」，但她的工作在玩家下一次行动开始时执行，她先到了院子。
- round141 第一句旁白最后一段是结算式的句子：「这个承诺不附带替谁隐瞒什么，也不表示她答应把任何东西交出来。」
- 第二句的 NPC 工作多加载了一个没用上的 materializeObject 表单。
- 「在场」页只核对了房间桌面状态和结构测试，没有在浏览器里看过。
