## 看到的

- **NPC 的决定在真实调用里都成立。** 回合计划、借机攻击的应答、看不见对手时只结束回合，都是本人视角、单次调用。
- **玩家地图战斗动作的旁白仍是薄弱处。** 走的是旧版旁白：它的规则检查会拒掉模型常写的距离和氛围，而能通过的旁白里仍有编出来的事实（先手顺序、距离、NPC 的动作）。要改走新版说明旁白，得先定"旁白失败时这一步算不算数"（新版旁白在提交前写好，失败则动作不生效）。房间测试显示，直接切换会让移动在旁白失败时不生效，并与借机攻击的续行冲突，所以本轮没有切换。
- **这一批暴露了两个产品缺口，都已交给后续实现。** 新版 KP 不能开战；玩家走不到模组的其他地点。
